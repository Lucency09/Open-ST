# 标注 M3 实施记录

日期：2026-09-17。依据：[已批准方案](design/annotation-m2-m3-v0.3.md)。
当前：模型、原位组件、图形及 App 接入已完成；后续职责整改及用户实机验收已完成，最新结论见文末和[实现进度](implementation_progress.md)。下方实现与自动验证保留 M3 交付时的阶段事实。

## 分工与实现

- Annotation 增加 Text／Mosaic 载荷、UTF-16／LF 规范化、明确字号和块档位、纯参数与正文替换；共享正文与擦痕计入去重预算。
- CaptureAnnotationState 统一管理对象参数和正文事务；原位编辑时不重复绘制活动文字，取消恢复；合法确认一步提交，已有空白拒绝删除原文。
- Common/WindowRenderer 提供 InlineTextEditor：系统 RichEdit 纯文本、多级控件撤销、组合输入准入、整项限长拒绝及 Resume；提取与表单共用的编码／字体辅助。
- App 只编排状态与控件；完成通知按序号排队，在回调返回后提交／回收。失败恢复同一控件，绘制或来源准备期间延迟完成与关闭。
- 合法的当前全局热键若与 Ctrl+A／V／X 等文字编辑键冲突，仅在本原位控件处于前台且持焦点时转发通用编辑动作；
  旧身份、过期消息、组合输入和完成排队均不转发，不修改用户配置，也不在后台粘贴。
- 属性表单增加字号与“编辑文字”意图，马赛克复用离散档位表单与实时预览；Toolbar 只增工具命令／图标。
- Graphics 用 DirectWrite 生成实际字形几何，绘制、命中和擦除共用；马赛克来源绑定一次冻结帧，按固定桌面网格生成完整块均值。
- AnnotationMosaicSource 在事务发布前准备候选，全部 overlay 与最终输出共享；CPU／GPU／几何缓存有界，关闭先释放目标再释放来源及冻结帧。

## 保持的交互

文字在截图落点直接输入；临时编辑底板、边框、光标不进入最终图像。Enter 换行，Ctrl+Enter 确认；
输入法组合中的 Enter／Esc 优先交给输入法，Ctrl+S 不完成截图；Ctrl+Z／Ctrl+Y 在正文编辑期间归控件内部。
选区内框外点击确认并吞掉该次点击；区外点击不提交。已有正文变为空白时保留编辑，不自动删除对象。
原位正文期间不并行切工具或打开属性；右键属性确认后可进入正文编辑，属性与正文分别形成编辑历史。

马赛克四档 4／8／16／32 px，默认 16，固定本次冻结桌面左上网格；跨屏先拼接 SDR 再按完整块平均，屏间空洞按黑色计入。
移动选区时采新位置的冻结像素，不能拖旧像素块。颜色和透明度不用于弱化马赛克；局部擦除及三种输出沿用统一链路。

## 验证

最终全量 710 项：698 通过、11 跳过，唯一失败为 D-066 已记录的贴图冗余位置请求。
Application 218 项全部通过；WindowRenderer 85 通过／1 人工跳过；其余新增文字、马赛克、擦除和模型测试均通过。
Debug／Release `/W4 /WX` 构建通过，可运行产物为 `build/Release/Open-ST.exe`。
过程中发现并修正了 RichEdit 实际软换行配置、字体测量方式，以及绘制批次返回后处理失捕屏障的时序，保留严格语义断言。
图形验证包含四档整块平均、负坐标跨屏网格、黑色空洞、移动重新取样、擦除孔洞、图层顺序、HDR GPU 回读及中日文字字形命中。
输入验证包含原生撤销／重做、超限整项拒绝、组合消息优先级、提交失败恢复同一控件，以及旧请求和延后指针序列隔离。
日志位于 `testing/testoutput/annotation-m3-all.log`；产品构建日志为 `build/annotation-m3-debug.log`、`build/annotation-m3-release.log`。
新增热键测试最初受系统前台限制影响，未通过时没有放松产品守卫；改用私有只读前台查询注入，同时操作真实 RichEdit，
分别断言前台与后台状态。生产默认仍查询真实 GetForegroundWindow，注入只用于隔离测试；粘贴消息由测试子类拦截，不访问用户剪贴板。
首轮旧贴图真实鼠标用例也曾受环境影响失败，最终全量已通过；未改其断言。既有冗余位置请求仍保留失败，不将全量写成全绿。
M3 自动验证完成时，真实中日输入法与混合 DPI 连续编辑尚待实际验收；后续用户反馈见下节，自动组合消息测试不能替代真实 IME。

## 后续用户实机验收（2026-09-17）

职责整改后，用户对文字、跨屏、属性与擦除、输出一致性四组检查明确反馈“都算通过了”，截图标注阶段据此收尾。
检查内容包括中文／多行和输入法 Enter／Esc、两层撤销、带标注选区跨屏往返与缩边裁剪、属性实时预览及取消恢复、局部擦除、四档马赛克，以及保存／复制／贴图不含编辑辅助界面。

此结论来自用户实机反馈；Computer Use 未能可靠定位遮罩，没有取得可据以判定上述场景通过的自动视觉证据。
日文输入法、具体混合 DPI 组合未逐项记录，不据整体通过反馈补写实测细节。D-066、复杂几何冷构建及其他独立后置事项不在本次关闭范围内。
最新职责整改回归仍为 721 项：709 通过、11 跳过、1 项既有 D-066 失败；此次文档同步未重跑测试。
