# Open-ST 产品需求规格

文档状态：首版目标需求已确认，按阶段实现

当前开发版本：`0.3.0`；已发布版本：`0.2.0`，发行说明见 [v0.2.0](releases/v0.2.0.md)。

最后整理：2026-09-18

本文描述产品目标，不表示当前开发版本已实现全部条目。当前已实现托盘与全局截图快捷键、设置语言切换、
多屏冻结与自由选区、HDR 到 SDR 输出、选区复制及 PNG/JPEG 保存，以及 A2 应用图标。欢迎页、开机自启、
截图工具栏、截图贴图、顶层窗口自动预选及 M1–M3 标注已接入，仍有各阶段人工验收；
UIA 子控件识别、OCR、翻译和完整设置页仍属后续工作；逐项状态以
[实现进度](implementation_progress.md) 为准。

## 1. 产品目标与边界

Open-ST 是一款面向 Windows 的截图、标注、本地文字识别和翻译工具。核心操作方式接近 Snipaste：按下全局快捷键进入冻结截图状态，选择区域，在选区附近的工具栏中完成复制、保存、贴图、标注、OCR 或翻译。

产品必须保持干净：

- 无广告、无捆绑软件、无后台服务。
- 同时提供当前用户／所有用户安装版及 ZIP 便携版；便携版完整解压后可运行。安装、更新及数据保留按已批准的安装发布方案执行。
- 不静默安装 vcpkg、编译器、运行库或其他全局工具。
- 不在 AppData 保存应用数据；可写状态统一放在可执行文件旁的 `data/`。
- 不自动保存截图历史和临时截图。
- 不以缩减功能或降低图像质量换取体积。完整发布包以 50 MiB 以下为优化目标，但不是硬门槛。

## 2. 平台

- Windows 10 22H2、Windows 11。
- x64 only，不提供 x86 或 ARM64 包。
- Per-Monitor V2 DPI awareness。
- 支持单屏和多屏，包括负坐标、不同分辨率、不同缩放率、横竖屏混用。
- SDR、HDR 和 SDR/HDR 混合显示器必须纳入设计与验收。

## 3. 程序生命周期

### 3.1 首次启动

- 显示欢迎窗口。
- 明确展示默认快捷键 `Ctrl+Alt+Q`。
- 明确展示开机自启默认开启，并允许用户修改。
- 解释隐私边界：OCR 完全本地；文本翻译只上传文字；图片翻译会上传处理后的图片。
- 欢迎流程完成后写入设置，后续启动不重复显示。

### 3.2 日常启动与单实例

- 日常启动后不弹主窗口，只显示托盘图标。
- 每个 Windows 用户仅允许一个实例。
- 第二次普通启动时，通知现有实例打开设置。
- 第二次以 `--capture` 启动时，通知现有实例开始截图。
- 单实例隔离按当前 Windows 用户处理，不能阻止其他用户会话各自运行。

### 3.3 托盘

- 左键单击：立即开始截图。
- 右键菜单：截图、设置、关于、退出。
- 双击：无行为，不打开设置。
- 正常退出时注销全局快捷键、关闭全部贴图并移除托盘图标。

### 3.4 开机自启

- 首次欢迎页告知用户后默认开启。
- 设置中可随时开关。
- 使用当前用户级 Windows 启动入口，不需要管理员权限。
- 关闭开机自启时立即删除对应入口。
- “退出并清理系统集成”应删除开机启动入口、注销快捷键、关闭贴图、移除托盘图标，并允许用户选择是否删除日志。

## 4. 设置窗口

设置至少包括：

- 界面语言选择，首版支持简体中文、英文和日文；不提供“跟随系统”，首次默认使用英文。
- 截图快捷键录入、冲突检测和恢复默认值。
- 开机自启开关。
- 截图是否包含进入截图瞬间的鼠标指针。
- 默认保存格式和 JPEG 质量。
- OCR fast/best 模型和识别语言。
- 文本翻译供应商及其参数。
- 图片翻译供应商及其参数。
- API Key 明文存储警告。
- 系统代理、直连、自定义 HTTP 代理。
- 恢复图片上传隐私提示。
- 打开日志目录、清理日志。
- 恢复全部现有可设置项默认值，执行前展示具体默认值并确认，确认后立即保存及生效，含语言与当前用户自启。
  首次欢迎状态、上次保存目录和未知字段保留；原“恢复本页默认”仍只修改草稿。

配置保存在 `data/settings.json`。API Key 按已确认要求使用明文，不做本地加密；UI 必须明确说明。如果程序所在目录不可写，应报告清晰错误，不能偷偷改用 AppData。

### 4.1 界面语言与文本资源

- 首版界面语言必须支持简体中文、英文和日文，语言标识分别使用 `zh-CN`、`en-US` 和 `ja-JP`。
- 窗口、消息框、托盘菜单、设置页、结果页和截图交互提示等用户可见文本必须从随应用分发的本地化资源配置读取，不得散落硬编码在业务代码中。
- 设置窗口从 `resources/ui_text.json` 动态读取语言代码并直接显示，例如 `zh-CN`、`en-US`、`ja-JP`；用户可添加其他语言，不维护固定选项清单。选择结果持久化到 `data/settings.json`；不提供“跟随系统”，没有已保存设置时默认使用 `en-US`。
- 本地化资源必须随发布包离线提供，切换语言不得访问网络，也不得影响 OCR 识别语言和翻译源语言/目标语言设置。
- 运行期间修改 `resources/ui_text.json` 无需重启；每次实际读取文本或语言列表时先检查文件版本，未变化则复用内存快照，变化后才重新读取。没有后台目录监听，也不要求静止界面主动刷新。
- 本地化配置以稳定文本键为第一层索引，每个文本键的值以动态语言代码为属性；不得采用“语言为第一层、文本键为第二层”的结构，也不得在 C++ 中维护语言代码清单。
- 允许新增语言的翻译暂不完整。查询缺少当前语言或值为空时回退同一 key 的 `en-US`；`en-US` 仍缺少时显示固定 `?` 并记录 key 与语言代码，不能显示空文本。
- JSON 语法损坏或固定外层协议无效时保留最后一份有效快照；同一份确定无效的文件签名不重复解析或刷日志，文件签名再次变化后重试。
- 动态文本必须支持受控占位符，例如版本号、快捷键和系统错误码；不得把任意配置内容直接当作格式字符串执行。
- 日志内部文本、协议字段和第三方 API 固定值不属于界面语言切换范围；会显示给用户的错误标题、错误阶段及操作提示属于本地化范围。

## 5. 全局快捷键

- 默认值：`Ctrl+Alt+Q`。
- 用户可在设置中修改。
- 注册失败或与其他程序冲突时给出明确提示，并保留可用的旧配置，不能静默失效。
- 快捷键触发后直接进入截图状态，不先打开主窗口。

## 6. 截图冻结与颜色正确性

### 6.1 捕获顺序

必须先捕获桌面，再显示遮罩窗口。捕获所得桌面帧在一次截图会话内不可变。

保存、复制、贴图、OCR、文本翻译和图片翻译都必须从这份不可变帧裁切；禁止在遮罩已经显示后重新抓屏，否则可能把遮罩、工具栏、选框或颜色效果截入结果。

### 6.2 遮罩

- 进入截图状态后全屏变暗。
- 当前选区保持原始颜色。
- 遮罩仅绘制在选区之外，选区之内不得叠加提亮、透明、饱和度、对比度或其他视觉修正。
- 窗口和 UI Automation 高亮只改变候选选区边界，不能处理源像素。
- SDR 无标注输出应与原始 BGRA8 捕获区域逐字节一致。

### 6.3 HDR

- 支持时采用 FP16/scRGB 捕获和编辑路径，避免过早压到 SDR。
- JPEG/PNG 输出使用一次明确、可测试的 HDR 到 SDR 色调映射，并输出 SDR/sRGB。
- 首版不导出 HDR 图片文件。
- HDR、SDR 与混合显示器下都要验证截图颜色和选区显示一致性。

## 7. 鼠标指针模式

设置提供：

- `HIDDEN`（默认）：任何输出都不包含鼠标指针。
- `FROZEN`：进入截图状态瞬间记录指针图像、热点和桌面位置。最终选区包含该指针时，才把它合成到结果；不包含则不输出。

进入截图后的实时操作指针只用于 UI，不能替换被冻结的指针，也不能在用户完成选区时重新读取位置。

## 8. 选区交互

- 鼠标悬停时检测顶层窗口。
- 可选用 UI Automation 进一步检测窗口内的子控件。
- 单击选择当前高亮窗口或控件。
- 按下并拖动创建自由矩形选区。
- 选区允许跨显示器和跨 DPI 区域。
- 已有选区显示八个缩放控制点，可调整边界。
- 工具栏默认显示在选区下方；空间不足时移到上方，并保证仍在可见工作区内。

0.3.0 顶层窗口首版已接入普通应用窗口、对话框和已有贴图，默认启用。桌面空白处不预选整屏；
任务栏、标准菜单和工具提示不纳入，也不穿透这些可见区域预选下面的普通窗口。
候选只显示边框，单击确认后才显示控制点和工具栏、允许完成快捷键；未确认时 Esc 直接退出截图，右键不操作。
候选上按住拖动超过系统容差后，从原按下点自由框选；无候选时沿用原小范围框选。
确认后的选区不会随悬停更换，清除后恢复预选。输出仍从原冻结桌面裁切，包含原有遮挡，不补抓隐藏内容。
窗口范围在遮罩创建前记录，会话内不跟随源 HWND 的后续变化；识别失败时保留手动框选。
半透明／异形及完全自绘菜单按顶层矩形近似，不承诺逐像素穿透识别。详细边界见
[窗口预选方案](design/window-selection-v0.3.md)。

快捷行为：

- `Ctrl+C`：复制选区并退出。
- `Ctrl+S`：保存选区并退出。
- `Enter`：复制选区并退出。
- `Esc`：按“取消当前工具操作 → 取消已有选区 → 退出截图状态”的顺序处理。
- 右键：空闲时命中标注元素直接打开其属性；空白、选区外、未框选或活动手势期间不操作。
- OCR 或翻译结果窗口打开后，原截图编辑器继续保留，用户可返回调整或执行其他操作。

## 9. 截图工具栏与标注

工具栏提供一个选择工具和其他绘图工具；完成框选或确认窗口选区后自动切换到选择工具。
选择工具移动截图区域、操作八个缩放控制点，不选择标注对象；其他工具只在选区内绘制，不能拖动截图控制点。
当前工具以持续变暗标识，保存、复制和置顶贴图仍是完成操作。标注随选区整体移动，边界调整只裁剪而不缩放标注。
Ctrl+Z 撤销标注及已提交的选区变更，Ctrl+Y／Ctrl+Shift+Z 重做；活动手势中 Ctrl+Z 只取消本次草稿。
绘图工具空闲时 Esc 先回到选择工具，再沿用选区取消层级。清空选区一起清空标注与历史。
右键元素可修改颜色、透明度及相应线宽／字号；马赛克只提供粗细档位，不改变当前工具或后续绘制默认值。
调整有效属性时实时预览；取消、关闭或 Esc 恢复打开前效果，确认后才保存最终值并记录一步撤销。
输入未完成或无效时保持上次有效预览；预览失败显示错误，成功重试前不能确认。
按可见几何优先命中最上层元素，空心内部不命中；完全透明元素跳过。一次确认对应一次撤销，取消或无变化不记历史。
已有元素可改为完全透明并撤销恢复，保留原 ID；右键拖动不触发属性。

截图完成后，在选区附近显示工具栏，首版提供：

- 保存。
- 复制到剪贴板。
- 固定到屏幕。
- 自由画笔。
- 直线。
- 箭头。
- 空心矩形。
- 椭圆。
- 文本。
- 马赛克。
- 实心矩形，提供直角和圆角版本，默认黑色；只有完全不透明的实际覆盖区域作为完全替换源像素的遮挡。
- 橡皮擦。
- 撤销、重做。
- 颜色选择。
- 透明度选择：0% 不透明、100% 完全透明；用于标注而非底图。完全透明绘制不产生不可见对象或历史。
- 线宽选择。
- 提取文字。
- 文本翻译。
- 图片翻译。

标注对象在当前会话内保持可编辑，输出时扁平化。不保存带图层的工程文件，不保存可恢复的编辑历史。
阶段边界：M1 提供空心矩形、箭头、直角／圆角实心矩形及预设／自定义颜色、透明度和线宽；
默认样式只在当前截图会话内保留。右键单元素属性及文字重新编辑已接入；对象单独移动、缩放和删除仍待后续细化。
M2 已接入画笔、直线、椭圆及局部橡皮擦，直径为 8／16／32／64 px；一次拖动一次撤销，擦痕随对象移动，后来新增对象不继承旧擦痕。
M3 已接入截图落点原位文字，Enter 换行、Ctrl+Enter 完成，输入法组合键优先，控件内 Ctrl+Z／Ctrl+Y 与截图历史隔离。
文字不自动软换行，编辑底板和光标不导出；已有文字右键属性中的“编辑文字”可重新编辑正文。已有正文改为空白不会自动删除对象。
四档矩形马赛克为 4／8／16／32 px，默认 16；以固定冻结桌面网格取样，移动选区后像素化新位置，不移动旧位置像素块。
未实现工具不得展示无效按钮；当前实际输入法、混合 DPI 及连续操作验收状态见实施记录。

进行图片翻译前，马赛克和实心矩形必须先扁平化到待上传像素；绝不能把未遮挡原图发送给供应商。

## 10. 保存和剪贴板

- 默认格式为 JPEG，可在设置选择 JPEG 或 PNG；截图与贴图保存均使用设置。保存窗口临时切换只影响当次。
- 默认 JPEG 质量：95，可通过滑条及数字框调整为 1–100；PNG 与复制不受 JPEG 质量影响。
- 可选格式：PNG。
- 默认文件名：`openst-yy-mm-dd_hh-mm-ss.mmm` 加扩展名，采用打开保存对话框时的本地时间；毫秒补齐三位，时间分隔符使用 Windows 文件名允许的连字符。初始扩展名随默认格式使用 `.jpg` 或 `.png`。用户可临时切换类型；后缀不匹配时在原保存窗口修正，再确认最终路径。
- 使用 Windows 系统保存对话框。
- 在 `settings.json` 记住上次保存目录。
- 复制操作把最终合成图像写入系统剪贴板。
- 不自动创建截图文件、历史库或临时截图缓存。

## 11. 固定到屏幕

贴图窗口用于把 Open-ST 截图或图片翻译结果固定在桌面作为参考，不是通用图片查看器。

- 支持多个贴图同时存在。
- 再次截图包含已有贴图当前显示的缩放、透明度及叠放外观；真实贴图全程保持显示，
  由冻结遮罩覆盖并接收选区输入，结束或取消后恢复贴图交互。
- 来源只允许当前 Open-ST 截图或 Open-ST 图片翻译结果。
- 不支持把剪贴板图片直接贴到屏幕。
- 支持拖动。
- 滚轮缩放。
- `Ctrl+滚轮` 调整透明度。
- 双击恢复 100% 显示。
- 支持复制、保存和关闭。
- 获得焦点的贴图按 `Esc` 关闭，与 Snipaste 的相关退出习惯一致。
- 退出 Open-ST 时关闭全部贴图。
- 重启应用后不恢复上次贴图。

## 12. 本地 OCR

- 使用 Tesseract + Leptonica。
- 截图像素和 OCR 中间数据不上传。
- 打包官方 `tessdata_fast` 与 `tessdata_best`。
- 两套均包含 `chi_sim`、`eng`、`jpn`。
- 默认使用 fast 模型和 `chi_sim+eng+jpn` 混合识别。
- 设置允许选择 fast/best，以及混合语言或某一种固定语言。
- OCR 在后台任务执行，不阻塞 UI。
- fast 模式典型选区目标在 2 秒内完成；best 允许更慢。
- 模型不提交 Git。构建清单固定官方 URL 和 SHA-256，构建时下载、校验、缓存和打包。

## 13. 文本翻译

文本翻译流程为本地 OCR 后只上传文字，不上传截图。

首版供应商：

- Google 网页翻译：默认选项，无内置 API Key；UI/文档需说明它不是有稳定契约保证的官方付费 API。
- OpenAI 兼容接口：Base URL、API Key、模型名。
- DeepL 官方 API。
- Microsoft Translator 官方 API。

默认源语言为自动检测，默认目标语言为简体中文。翻译结果窗口允许临时切换目标语言，也允许用户修改 OCR 文本后重新翻译。

## 14. 图片翻译

- 首个供应商为百度图片翻译 API。
- 核心代码通过 `IImageTranslationProvider` 抽象，便于增加其他供应商。
- 上传内容是已裁切、已合成标注、已扁平化马赛克/实心遮挡的图像。
- 第一次图片上传前显示明确隐私警告。
- 用户可选择“不再提醒”，并可在设置中恢复提醒。
- 图片翻译结果可打开为结果窗口，也可固定到屏幕。

## 15. 网络、安全与代理

- 使用供应商规定的认证和传输方式。
- 默认要求 HTTPS，并正常执行 Windows 证书校验。
- 不提供关闭证书验证的选项。
- 配置 HTTP 端点时显示醒目风险警告。
- 代理模式：Windows 系统代理（默认）、直连、自定义 HTTP 代理。
- 自定义代理允许 `127.0.0.1:7897`。
- 文本翻译连接超时 10 秒，总超时 30 秒。
- 图片翻译总超时 90 秒。
- 所有网络操作都必须允许用户取消。
- 可能计费的翻译请求不自动重试。
- 百度访问令牌获取可以自动重试一次。

## 16. 项目主页和版本

- 使用语义化版本，初始开发版本为 `0.1.0`。
- Debug 界面显示 Git 短提交号；Release 只显示语义化版本。
- 项目主页 URL 放在开发阶段配置文件中，构建时生成常量并编译进程序。
- 项目仓库已确定为 `https://github.com/Lucency09/Open-ST`，默认分支为 `master`；当前版本模板中的主页常量仍为空，程序内主页入口尚未实现。
- 关于窗口提供“检查更新”：查询 GitHub 最新正式 Release，已最新时提示；有新版先确认，再按发行模式下载打开 Setup 或打开发布页。发行模式由 Settings 默认资源的 distribution.mode 标识，不由用户 data 配置覆盖。
- URL 为空时显示“项目主页尚未配置”。
- 不做后台定时检查、静默安装或升级服务；下载与打开 Setup 仅在用户确认后执行，安装步骤仍由标准安装器交互完成。

## 17. 日志与隐私

- 日志目录：`data/logs/`。
- 文件按创建时刻命名为 `Open-ST-YYYY-MM-DD-HH-mm-ss-SSS.log`，时间精确到毫秒；每次轮换都重新取当时时间戳，同一毫秒发生命名碰撞时才追加 `-001`、`-002` 等序号。
- 单文件默认最多 10000 行，同时保留 2 MiB 文件大小安全上限，任一条件达到即轮换。
- 默认保留最近 3 个项目日志文件，启动及轮换清理超额历史；其他进程活跃文件不属于删除目标，保留数可暂时超过该值。
- 程序重启后可继续追加当天最后一个未满且没有其他进程使用的时间戳日志；活跃文件由各进程独占，已满或被占用的日志不共写，另建本进程日志。仅同毫秒名称冲突时追加序号。
- Debug 构建记录 Debug 及以上级别；Release 构建记录 Info 及以上级别，并在编译期移除 Debug 调用及其参数求值。
- 每行均记录本地日期和精确到毫秒的时间；Debug 构建额外记录调用点相对项目根目录的源码路径和行号，Release 不记录源码位置。
- 日志同步、线程安全且不使用第三方日志库；Error 和 Fatal 立即刷新，普通日志允许使用文件流缓冲。
- 日志初始化、格式化、写入、刷新、轮换或清理失败不得导致应用崩溃，也不得阻断截图、OCR 或翻译流程。
- 不记录截图、OCR 文本、翻译文本、API Key、Authorization 请求头、完整请求体或完整响应体。
- 默认不生成大型内存转储。
- 维护页提供打开日志目录和清理历史日志；保留所有进程正在写入的日志，清理不停止日志记录，部分失败可由用户重试。跨进程协调锁占用时立即失败并提示，不等待、不自动重试。

## 18. 性能目标

- 典型机器从快捷键触发到显示冻结遮罩：不超过 150 ms。
- 选区调整和绘制：目标 60 FPS。
- 托盘空闲时 CPU 约为零，不连续轮询桌面。
- OCR 模型加载前空闲内存：目标不超过 80 MiB。
- 完整发布包：目标小于 50 MiB，但不作为牺牲功能和质量的理由。

## 19. 明确不做

- 不采用 Qt、WPF/.NET、Electron、WebView2 或 SDL 作为应用主框架。
- 不采用 D3D12 作为首版渲染基础。
- 不提供剪贴板图片直接贴屏。
- 不自动保存截图历史。
- 不提供 Windows 服务、静默自动升级或后台定时版本检查。手动检查更新位于关于窗口，发现新版须先确认；安装版随后下载、校验并打开 Setup，便携版打开固定版本发布页。
- 不提交构建目录、发布产物、手工下载的第三方 DLL/库或来源不明二进制。
