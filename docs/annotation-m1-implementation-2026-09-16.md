# 截图标注 M1 实现与验证

日期：2026-09-16。状态：M1 代码和自动验证完成，实际产品界面待用户验收。
依据：[已批准方案](design/annotation-v0.3.md)。本阶段不包括 M2 局部橡皮擦或 M3 马赛克等后续工具。

## 已实现

- 框选／窗口确认后自动选择工具；选择工具仅移动和八控制点缩放截图区域，绘图工具不抢占这些操作。
- 空心矩形、箭头、直角实心矩形、圆角实心矩形，当前工具持续深灰标识；工具栏支持窄工作区换行。
- 默认绘制样式：六色预设、自定义 #RRGGBB、透明度滑条／数值、适用工具的 1／2／3／5／8 px 线宽。
  透明度 0% 不透明、100% 完全透明；完全透明手势不提交对象。直角／圆角填充共用本会话默认样式，初始黑色。
- 标注随选区整体移动；缩放截图边界只改变裁剪，扩大区域可重新看到原有内容。越界箭头保持真实方向，由图形层裁剪。
- Ctrl+Z、Ctrl+Y／Ctrl+Shift+Z；一个已提交拖动一步历史，选区和对象一起恢复。活动手势中撤销只取消该手势。
  新编辑成功才清除 redo，保留最多 128 步；对象上限 1024，预算失败保留原文档和历史。
- Esc／右键先取消活动操作，再从绘图工具退回选择工具，再按原选区取消层级处理。
- 复制、保存、贴图都固定已提交快照，并调用同一最终图像生成入口。样式和错误提示期间保护全部屏幕的编辑状态。

默认样式仅在一次截图会话内保留，没有新增持久化设置字段。为避免全局截图键吞掉编辑键，
Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z 与既有 Ctrl+C／Ctrl+S 一样属于保留的会话组合；旧配置占用时按既有非法配置路径提示／回退，不静默改写 JSON。

## 模块与图像链路

`Graphics/Annotation` 只定义标准库对象、样式和只读快照；App 的 `CaptureAnnotationState` 管理草稿和统一历史。
预览与输出复用 `annotation_drawing.cpp` 的 D2D 几何，箭头采用一个无重叠闭合轮廓，避免头部和杆身重复施加透明度。
HDR 预览的原冻结图保持原样，仅将标注 sRGB 色解码并按该屏参考白映射到 scRGB。

最终输出先走既有裁切及一次 HDR→SDR，再以 WIC/D2D BGRA 预乘透明层按 sRGB 编码通道合成。
透明层外保留 BGRX 四字节；没有标注时直接使用旧路径，不做额外整图往返。
实心矩形的完全不透明实际覆盖替换底图；半透明和圆角外区域不作完整遮挡承诺。
不保存临时截图、标注工程或编辑历史，不上传任何图像。
