# Open-ST 非功能整改报告

日期：2026-09-12。适用版本：当前开发版 0.3.0。

## 1. 结果与范围

本次依据用户审核后的整改表施工，处理重复逻辑、依赖边界、数值与异常边界，以及保持既有行为的性能优化。共 17 项完成；R-15 完成剪贴板部分，显示上传部分经评估保留；R-16 保留公开兼容接口。R-01、R-21、R-22 三项专项未实施。

Debug、Release 产品构建均通过 `/W4 /WX`。全量 Debug 注册 370 项测试：结合原断言权限复跑，361 项取得通过结果、9 项条件跳过，没有未解决失败。两项独立 Release 内存基准另行执行并通过像素等价校验。

代码复核和已执行的自动回归未发现新增功能回归。此结论限于已验证路径，不代表完整产品人工视觉验收已经通过。修复数值溢出、滚动范围和保存后的错误分类，是使异常与边界行为符合原设计，不增加产品功能。

施工由主 Agent 按小步骤整合，子 Agent 分担设置与公共接口、布局与像素路径，并进行交叉复核；脚本、空目录和部分机械检查交给较低成本的 Luna。未提交 Git commit；用户原有 `.gitignore` 修改保留。

## 5. 性能测量

以下为本机 Release、3840×2160 内存输入、九个样本中位数。像素基准先预热；结果均检查字节一致，不设置依赖机器速度的通过阈值。

| 路径 | 对照耗时 | 当前耗时 | 对照含义 |
| --- | ---: | ---: | --- |
| BGRA8 捕获构造 | 13.6703 ms | 3.5277 ms | 逐像素参考复制，对比当前完整 plane 构造。 |
| BGRA8 预览构造 | 24.8532 ms | 3.3593 ms | 逐像素参考复制，对比当前完整预览构造。 |
| FP16 捕获构造 | 16.4934 ms | 6.4772 ms | 逐像素参考复制，对比当前完整 plane 构造。 |
| FP16 预览构造 | 26.5720 ms | 7.2221 ms | 逐像素参考格式分派，对比当前完整预览构造。 |
| 剪贴板 DIB 准备 | 8.8182 ms | 5.1734 ms | 临时 DIB 加整帧复制，对比直接填充；两者都使用内存替身。 |

4K 剪贴板省去的临时缓冲为 `3840 × 2160 × 4 + sizeof(BITMAPINFOHEADER) = 33177640` 字节，约 31.64 MiB。这是明确消除的分配量，不是实测进程峰值工作集差值。

像素对照不是旧版产品全链路，且测量不含桌面获取、系统剪贴板发布、GPU 呈现或用户交互。上述数据用于确认这些内存路径的收益，不推导整体截图性能比例。R-07 没有进行前后耗时测量。

基准构建目录为 `testing/testoutput/Debug/benchmark-release/`，使用 Release、测试 feature 和 `OPEN_ST_BUILD_TESTS=ON`，单独构建 `open_st_pixel_copy_benchmarks`、`open_st_export_tests`。分别设置进程环境变量 `OPEN_ST_PIXEL_COPY_BENCHMARKS=1`、`OPEN_ST_EXPORT_BENCHMARKS=1`，执行对应基准用例；测试后清除变量。结果日志由 CTest 保存在该目录的 `Testing/Temporary/LastTest.log`。
