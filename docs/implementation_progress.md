- [x] `localization` 模块通过 Common 句柄加载文本键优先的动态多语言 JSON，默认/回退为 `en-US`，支持命名占位符，不再自行读取设置文件。
- [x] 业务通过 `GetUiText("text.key", ...)` 动态查询文本；设置窗口经 Application 注入的窄回调转发，不产生兄弟依赖，不维护 C++ key 枚举或映射表。
- [x] 本地化资源按需热更新，无后台监听；模块锁串行读取、业务校验与接受内容，不依赖 Common 版本。语言动态发现，译文回退英文再回退 `?`，读取或结构失败保留已生效业务文本，Common 本次读取仍返回失败。
- [x] 运行期读取故障由 Settings/Localization 分别去重，Application 合并显示本地化粗略告警；截图期间推迟提示，启动与保存失败沿用现有提示，详细原因保留在日志。
- [x] 设置窗口从托盘打开，动态读取语言代码，确定后保存并切换，取消不生效；Windows 11 请求 DWM 系统圆角，旧系统方角降级；跨不同 DPI 显示器时重排控件并重建系统字体。
- [x] `graphics` 内部自由选区状态机：支持四向创建、整体移动、八控制点缩放和跨边翻转；选区外按下无效果，取消按“当前拖动 → 已有选区 → 覆盖窗口”分层处理。
- [x] 覆盖窗口使用虚拟桌面物理坐标和鼠标捕获驱动选区；Application 每次截图从 Settings 读取 `capture.selection_border_color` 并传入各屏 Graphics，严格解析 `#RRGGBB`，缺失或非法回退纯黑，8×8 控制点白色填充不变。
- [x] 12×12 半开控制点命中区、真实可达桌面右/下边缘、选区外遮罩的裁剪/贴边/负坐标/不重叠行为均有自动测试。
- [x] 产品构建和发布打包会携带 EXE、运行时 DLL、`resources/ui_text.json`、`resources/default_settings.json`、第三方通知与 nlohmann/json MIT 许可证，不携带 CMakeFiles、OBJ、LIB 或 PDB。
