# OCR 实施与验证记录（2026-09-25）

## 结论与交付范围

用户批准 [OCR 方案](design/ocr-v0.4.md) 后完成本地识别、结果编辑/复制、设置和构建发布接入。当前仅为开发树与本地候选，未提交 Git、未公开发布；公开 v0.3.0 不含本次 OCR。源码版本暂仍为 0.3.0，下一次发行前需另行确定新版本，不能将本地同名候选与公开资产混用。

可运行产物：`build/Release/Open-ST.exe`（OCR=ON）。用户反馈 Debug 未显示入口后，已重新启用并构建 Debug；当前 Debug 和 Release 均保留 OCR=ON，六模型哈希复核通过。用户随后要求直接用脚本变量配置：build.ps1/test.ps1 顶部 `$EnableOcr = $true`，正常构建无需额外参数；需要关闭时改为 false。本地 Setup/ZIP 位于 `artifacts/0.3.0/`，以本次 build-record.json、SHA256SUMS 区分；不得直接替换远端 v0.3.0 资产。

## 实现与职责

- Application/OCR 独占像素副本、模型白名单/加载、Leptonica预处理、Tesseract和单工作线程；结果、取消与忙状态只有一个所有者。模型在加载前经Common SHA-256验证，从同一份内存初始化，不再按路径重读。
- OcrSession负责请求与截图生命周期、结果窗关联和通知补收；OcrResultWindow仅持可编辑草稿并复用WindowRenderer。完成结果只填充一次，状态刷新不覆盖用户编辑和撤销。
- App仅新增命令/参数适配与生命周期接入；Graphics正式裁切、HDR转换及标注合成算法没有新增实现。马赛克/遮挡后的图像参与识别，不读取被遮挡原文。
- WindowRenderer补公共多行编辑、行数/滚动/文本上限、IME与注册热键路由；Export补Unicode文本复制并复用剪贴板会话/内存代码。Common提取增量SHA-256，Update迁移旧实现，移除重复算法资源管理。
- Settings选项由OCR领域列表经App注入，保持兄弟模块无依赖；保存/冲突/忙错误/默认恢复沿用既有事务。模型与运行DLL纳入既有统一staging及ZIP/Setup清单。
- 取消立即撤销发布资格，后台结束前拒绝新任务；关闭结果不join。结果窗纳入模态输入暂停，普通退出和退出清理先异步等待OCR结束，再释放日志；“保留日志并退出”优先于晚到完成通知。

子Agent复核了职责、公共复用、输入和退出边界。发现的模态结果窗未暂停、退出清理先关日志及取消后晚完成可能继续清理等问题均已修复并复核；当前复核范围无遗留阻塞P1/P2。退出清理顺序为代码复核证据，未操作用户真实日志验证。

## 性能与小字验证

设备：AMD Ryzen 7 9800X3D；Release优化探针直接调用当前OCR源码与最终发布目录的模型/DLL。当前vcpkg固定Tesseract 5.5.1、Leptonica 1.85.0，未启用OpenMP。
自有GDI生成1200×800英/中/日/混合、深色、小字及空白图片；基准文件不含用户截图。下表为单轮样本，冷指本次模型实例首次加载，操作系统文件缓存未清除。

| 最终混合样本 | 首次加载并识别 | 缓存模型后识别 | 识别后私有内存 |
| --- | --- | --- | --- |
| fast | 约309 ms | 约220 ms | 约102 MiB |
| best | 约483 ms | 约423 ms | 约123 MiB |

该探针进程fast阶段累计峰值工作集约154 MiB，全部顺序样例峰值约180 MiB；不是完整截图应用的内存增量。测量包括输入复制、模型加载/预处理/识别和结果收取，不包括桌面抓取、正式图像合成、UI创建与文字显示，因此不据此宣称所有截图端到端均小于2秒。

初始fast在18物理像素字号的混合样本返回空白，best字符错误率约6.12%。实验证明对不超过1600×1200输入一次2倍插值可把该样本两档CER降至0，常规/深色/空白未回退；正式实现采用该预处理，仍验证扩展后像素预算，不执行多轮识别或缩小大图。
更小14像素实验仍有约4.08%（fast）/6.12%（best）错误，不能保证任意小字准确。字符错误率统计忽略空白、保留标点与大小写；真实引擎自动测试保留容差，不以有限样例CER0替代通用准确率。

原生多行EDIT的100万连续字符极端装载测试曾耗时约17.75秒，最终全量同组受系统负载也有波动；当前保持已批准的结果上限，不静默截断。模型初始化/部分版面分析也不保证立即取消，UI不join但进程退出可能等待后台完成。这些限制未标记为解决。
测量记录：`testing/testoutput/ocr-performance-final.csv`、`ocr-performance.csv`、`ocr-scale-experiment/scaling-results.csv`、`ocr-scale-experiment/`中的14像素实验。

## 待人工验收与后置限制

1. 用实际中英日截图识别，编辑后复制，检查中文IME选字、Enter/Esc/Ctrl+Z和配置成编辑键的全局热键。
2. 识别期间拖动/缩放跨屏选区、编辑标注；旧结果保持快照语义，关闭结果重新识别后反映新图；保存/复制/贴图原行为保留。
3. 检查HDR、混合DPI、马赛克遮挡与复杂密集正文；结果窗和模态属性/保存窗口的层级及焦点。
4. 核验快捷取消、退出和真实安装目录的离线识别；Windows10、所有用户多会话等原安装验收缺口仍保留。

本轮自动用例和引擎探针不等同用户视觉验收。人工验收通过后，再进入文本翻译方案设计；翻译没有提前接入。
