# Open-ST v0.3.0

本版新增完整截图标注、顶层窗口预选、可配置快捷键、安装包及关于窗口更新功能，并修复已反馈的跨屏拖动掉帧问题。

## 下载与运行

- **安装版**：`Open-ST-0.3.0-win-x64-Setup.exe`，支持当前用户／所有用户安装及自定义本地目录。
- **便携版**：`Open-ST-0.3.0-win-x64.zip`，完整解压到可写目录后运行 `Open-ST.exe`。
- **校验文件**：`SHA256SUMS.txt`，包含上述两个发行包的 SHA-256。
- 目标平台为 Windows 10 22H2／Windows 11 x64；本轮真实安装验收在 Windows 11 完成。
- 安装包内含经核验的微软 VC++ x64 运行库安装程序，缺失时提示用户确认；ZIP 不含运行库安装程序，可从[微软官方说明](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist)获取。
- Open-ST 程序和 Setup **未签名**，Windows 可能显示发布者或信誉提示；SHA-256 校验不等于发布者数字签名。

## 相比 v0.2.0 的变化

- 顶层窗口自动预选；框选后可移动和八个控制点缩放。
- 完整标注：矩形、箭头、直角／圆角实心矩形、画笔、直线、椭圆、局部橡皮擦、原位文字和四档马赛克。
- 默认颜色、透明度和线宽；右键编辑单个元素属性并实时预览，取消恢复，确认后可撤销。
- 标注随选区整体移动，调整边界只裁剪；复制、保存与贴图使用统一标注输出。
- `Ctrl+Z`、`Ctrl+Y` 撤销／重做；文字编辑期间优先处理控件内历史，输入法组合键不直接结束截图。
- 修复用户反馈的按住鼠标跨屏移动选区时第二屏重绘机会不足问题。
- 可配置截图快捷键、图片格式／质量、日志维护及恢复设置。
- 安装器提供安装、同范围原路径升级、数据保留卸载及原路径重装。
- 关于窗口提供“检查更新”：先查询并确认；安装版下载、校验并打开新版 Setup，便携版打开该版本发布页。
- 共享配置的跨进程文件协调与日志活跃文件保护；锁占用立即报错，不等待、不自动重试。

## 使用与升级

- 默认 `Ctrl+Alt+Q` 截图，`Ctrl+C` 或 `Enter` 复制，`Ctrl+S` 保存，`Esc` 分层取消。
- **右键不再取消截图**；空闲时右键标注元素可编辑属性。
- 文字工具支持多行；`Enter` 换行、`Ctrl+Enter` 确认，输入法组合期间优先交给输入法。
- 安装升级前保存工作并从托盘退出使用该目录的实例；安装器不强制结束程序。
- 从旧 ZIP 转为安装版，请选择新目录安装，再显式迁移备份的 `data/`；安装器不直接接管旧 ZIP 目录。
- 便携版升级前退出旧程序，备份 `data/`，替换程序与资源并保留数据。修改过的语言资源请先备份，不直接覆盖新版结构。
- 所有用户安装仍共享 EXE 旁的 `data/`。卸载默认保留数据及本路径重装归属记录；各用户的开机启动登记仍独立，管理员卸载不跨账户清理其他用户自启。

## 验证与已知限制

- Debug／Release `/W4 /WX` 构建通过。全量 771 项：**758 通过、12 条件跳过、1 项既有失败**。
- 唯一失败为 D-066：贴图顺序正确时仍产生冗余窗口位置请求；没有修改断言掩盖，也未将该优化标记完成。
- 本轮已验证当前用户安装、同版本修复、修改资源备份、保留数据卸载与原路径重装、中文空格路径、目录占用拒绝，以及关于窗口确认／取消／分流的自动集成契约。
- 截图标注的文字、跨屏、属性／擦除及输出一致性已获用户实机确认。复杂几何的首次构建仍可能较慢；独立显示 FPS、144 Hz 更新、HDR 综合色彩和设备丢失恢复仍有后置事项。
- Windows 10 实机、所有用户提权／真实多账户、缺运行库／重启分支、显式删除数据、不同版本覆盖升级，以及远端下载并执行真实新 Setup 的完整流程尚未逐项实机验收。
- UI Automation 子控件识别、冻结鼠标指针、OCR 和翻译尚未接入。

项目采用 MIT；第三方许可随包提供。发布只附带 Setup、ZIP 和 SHA256SUMS，不上传本机测试日志或含开发机路径的构建记录。
