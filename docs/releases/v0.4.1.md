# Open-ST v0.4.1

本版修复安装更新时托盘右键无响应：安装器已启动，但“关于”窗口仍保持模态，导致用户无法按安装提示从托盘退出旧程序。

## 修复内容

- 安装器成功启动且下载文件完成保留交接后，自动关闭“关于”窗口，恢复托盘操作。
- 不强制退出 Open-ST 或丢弃贴图，仍由用户按安装提示退出；安装器启动失败时保留窗口，允许重试和关闭。
- 补齐更新确认窗口“取消”按钮的中英日文案。
- 本地中英日 OCR、fast/best 模型及其他 v0.4.0 功能继续默认包含，翻译尚未接入。

## 下载与升级

- 安装版：`Open-ST-0.4.1-win-x64-Setup.exe`。
- 便携版：`Open-ST-0.4.1-win-x64.zip`。
- 校验文件：`SHA256SUMS.txt`。
- **从旧版升级到本版时，旧进程还没有此修复。** 如果托盘无响应，请先关闭旧程序的“关于”窗口，再从托盘退出，然后重试安装；也可先退出旧程序，再直接打开本版 Setup。
- 升级前备份 `data/`，安装默认保留数据；便携版完整覆盖程序、资源和运行库，保留 `data/`。
- 目标平台为 Windows 10 22H2／Windows 11 x64；Setup 附带经核验的微软 VC++ x64 运行库，缺失时请求确认。ZIP 需自行准备运行库。
- 程序和 Setup 仍**未签名**，Windows 可能显示未知发布者或信誉提示。

## 验证与限制

- Debug／Release `/W4 /WX` 构建通过；6项关于窗口集成用例通过，覆盖成功后自动结束模态、交接文件保留、启动失败重试和关闭等。旧实现可在新用例下复现超时。
- 更新模块22项回归：21通过、1项既有符号链接权限跳过，无失败。
- 修复范围限更新窗口交接和本地化资源；不修改下载校验、安装维护租约或OCR引擎。
- v0.4.0 的全量815项记录（802通过、12条件跳过、1既有D-066失败）及其他限制继续保留，不宣称本次重新完成全部实机验收。
- 已知限制仍包括 D-066 贴图冗余位置请求、OCR极端长文本显示较慢、部分引擎阶段不能即时取消，以及Windows10、多账户、HDR/DPI等实机验收缺口。详见[v0.4.0说明](https://github.com/Lucency09/Open-ST/releases/tag/v0.4.0)。

仅发布Setup、ZIP与SHA256SUMS；模型、依赖和第三方许可证随包提供，不上传用户数据或本机构建记录。
