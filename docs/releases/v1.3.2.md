# Open-ST v1.3.2

修复两块显示器分别接在集显和独显上时，截图可能反复提示“覆盖交换链关联的显示输出与冻结帧不一致”的问题。现在每块屏都由连接它的显卡渲染截图遮罩。截图过程中若显示布局变化，日志会记录目标屏和查询结果，便于定位。

## 下载与升级

- 安装版 `Open-ST-1.3.2-win-x64-Setup.exe`
- 便携版 `Open-ST-1.3.2-win-x64.zip`
- 校验清单 `SHA256SUMS.txt`

两种发行包均包含离线 OCR 和中英翻译模型。升级前请保存未完成的截图或编辑，并备份程序旁的 `data` 目录。手动升级便携版时，请先退出程序并保留该目录。

## 验证与运行环境

15 项定向测试通过，覆盖跨显卡选屏、同卡双屏和显示布局变化。在 NVIDIA 与 AMD 各接一屏的机器上，两屏均成功呈现测试帧。实际热键截图中的 HDR 外观仍待目视复核。

适用于 Windows 10 22H2 和 Windows 11 x64。程序与安装包均未签名，可使用随附的 SHA-256 清单核对下载文件。
