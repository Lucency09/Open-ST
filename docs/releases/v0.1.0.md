# Open-ST v0.1.0

首个开发版本，提供基础截图、复制和保存功能。

## 下载与运行

- 系统：Windows 10 22H2 / Windows 11，x64。
- 下载 `Open-ST-0.1.0-win-x64.zip`，完整解压到可写目录后运行 `Open-ST.exe`。
- 需要 [Microsoft Visual C++ v14 x64 运行库](https://aka.ms/vc14/vc_redist.x64.exe)，运行库未包含在ZIP内。
- 用户设置与日志保存在程序旁的 `data/`；更新时保留自己的 `data/` 目录。
- 附带 `SHA256SUMS.txt` 用于校验下载文件。

## 当前功能

- `Ctrl+Alt+Q` 或托盘菜单启动截图，支持多显示器自由选区、移动和八方向缩放。
- `Ctrl+C` / `Enter` 复制；`Ctrl+S` 保存 PNG / JPEG；`Esc` 或右键分层取消。
- 默认文件名包含本地时间及三位毫秒，记忆上次保存目录。
- HDR 原生桌面捕获，导出为 SDR 图片；快速移动鼠标时按每显示输出500ms预算等待有效画面。
- 中文、英文、日文界面，持久化设置，A2 应用图标。

## 尚未实现与已知限制

- 截图工具栏、窗口自动识别、标注、贴图、OCR和翻译尚未实现。
- HDR 跨屏交互可能掉帧，部分显示环境的颜色与性能仍待完善。
- 设备丢失及桌面复制访问丢失后的自动恢复尚未完成。
