# Open-ST v1.3.0

本版增加长文本自动分段和每个翻译接口独立代理。

- 长文本按句末、换行等边界自动分段，依次调用本地或在线接口，全部完成后拼接译文，无需额外设置。
- 每个在线接口可在新增/编辑窗口独立选择跟随系统、直连或自定义HTTP代理。
- 删除全局“翻译网络”设置页；升级时旧全局代理迁入尚无网络配置的在线接口，已有独立配置保留。
- 测试连接使用当前未保存的接口草稿；有序后备使用下一接口自己的代理。本地接口不显示网络配置。

安装包和便携包均含离线OCR与中英翻译模型。升级前保存未完成工作并备份data；便携版手动覆盖时保留data。Setup会关闭核验过的目标实例，卸载默认保留data。

## 下载

- `Open-ST-1.3.0-win-x64-Setup.exe`：安装版，支持当前用户/所有用户及自定义目录。
- `Open-ST-1.3.0-win-x64.zip`：便携版，完整解压到可写目录后运行。
- `SHA256SUMS.txt`：上述两件资产的SHA-256校验清单。

目标平台为Windows 10 22H2 / Windows 11 x64。程序及Setup未签名；校验和只用于完整性验证，不是发布者签名。

## 验证与限制

- 分段功能已有95项定向用例通过；接口代理有268项定向用例通过，另1项欢迎窗口人工用例默认跳过。这两组存在重叠，不累加为独立测试总数。
- 自动分段按固定200 Unicode标量向下选择边界，极长无边界文本仍需硬切；自动语言检测按片段进行，本地模型仍可能误译或漏译。
- 普通翻译全文上限100000标量，连接测试仍为单次完整请求、上限10000标量；整轮120秒及总输出预算不因分段而增加。
- 直连仅指不使用HTTP代理，不改变VPN或底层网络路由。自定义代理失败不会自行直连。
- 已完成真实窗口自动化测试，新编辑布局完整视觉/DPI验收尚未完成。Windows10、多账户/提权和缺运行库等安装矩阵仍有实机验收缺口；既有贴图冗余定位、复杂标注性能等后续事项保留。
