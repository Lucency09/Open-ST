# Open-ST v0.2.0

本版新增截图工具栏和多张置顶贴图，并完善设置窗口、首次欢迎与开机启动。

## 下载与运行

- 系统：Windows 10 22H2 / Windows 11，x64。
- 下载 `Open-ST-0.2.0-win-x64.zip`，完整解压到可写目录后运行 `Open-ST.exe`。
- 需要 [Microsoft Visual C++ v14 x64 运行库](https://aka.ms/vc14/vc_redist.x64.exe)，ZIP 不包含运行库安装程序。
- 更新前从托盘退出旧程序，备份并保留原有 `data/` 目录；用新版程序、资源和许可证替换旧文件。
- 首次欢迎页默认勾选开机启动，可取消勾选；确认后才保存设置并应用。移动程序目录后可在设置中修复启动路径。
- 附带 `SHA256SUMS.txt` 用于校验下载文件。

## 相比 v0.1.0 的变化

- 新增截图工具栏：取消、贴图、保存、复制；与键盘完成命令共享选区和忙状态，避免重复操作。
- 新增多张置顶贴图：可拖动，点击后滚轮缩放，`Ctrl+滚轮` 调整透明度，双击恢复原始缩放；焦点贴图按 `Esc` 关闭。
- 贴图保持固定叠放顺序，右键可手动提层、复制、保存或关闭；托盘支持关闭全部贴图。
- 贴图复制、保存使用独立原图，不烘焙显示缩放和透明度。再次截图包含已有贴图当前外观，真实贴图保持显示，由截图遮罩直接覆盖。
- 重做设置窗口：JSON 布局、标签页框架、语言草稿、应用/取消、恢复本页默认和重新加载。
- 新增首次欢迎、当前用户开机启动、路径修复和退出清理；完善同一用户的单实例和启动命令分派。
- 改善置顶窗口下的错误提示层级、模态期间的窗口生命周期与输入暂停处理。

保留多显示器自由选区、HDR 原生捕获与 SDR 输出、PNG/JPEG 保存，以及中英日界面。
快捷键仍为 `Ctrl+Alt+Q` 截图、`Ctrl+C` / `Enter` 复制、`Ctrl+S` 保存、`Esc` / 右键分层取消。

## 尚未实现与已知限制

- 窗口/UIA 自动识别、标注、OCR 和翻译尚未实现。
- 独立快捷键管理、快捷键设置、截图/存储及日志维护等完整设置页尚未完成；鼠标指针冻结合成未实现。
- HDR 颜色、跨屏交互与性能仍待完善；设备丢失及桌面复制访问丢失后的自动恢复尚未完成。
- 真实登录、自启禁用、跨会话、多语言/跨 DPI 与部分产品视觉流程仍需人工验收，自动测试通过不代表这些场景已全部验证。

## 验证与许可

Release `/W4 /WX` 构建及版本化打包通过。发布前全量测试共 **351 项，344 项取得通过结果，7 项条件跳过**。
其中真实鼠标拖动测试首轮出现 1 像素坐标偏差，保持代码与断言不变后单独复跑通过；保留其桌面输入环境敏感性记录。
跳过项为两项符号链接权限检查、四项人工窗口及一个仅由父测试启动的子进程入口，不视为人工验收通过。
