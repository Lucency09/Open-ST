# Open-ST v1.3.1

修复翻译接口编辑窗口在滚动、状态或错误提示变化后出现的文字重叠、边框残留和局部裁切。

窗口完成控件排列后统一重绘可见区域，保持首次显示、焦点和输入行为。接口配置、代理连接方式、翻译逻辑及表单尺寸保持原样。

## 下载与升级

- `Open-ST-1.3.1-win-x64-Setup.exe`：安装版。
- `Open-ST-1.3.1-win-x64.zip`：便携版。
- `SHA256SUMS.txt`：两件安装资产的SHA-256校验清单。

两种包均包含离线OCR和中英翻译模型。升级前保存未完成工作并备份data；手动覆盖便携版时保留data。Setup会关闭核验过的目标实例，卸载默认保留data。

## 验证与限制

- 29项定向测试通过，涵盖真实窗口像素对比、滚动、DPI、焦点、编辑输入和接口编辑；旧实现的残影可被新增用例稳定捕获，修复后像素对照一致。
- 目标平台为Windows 10 22H2 / Windows 11 x64。程序与Setup未签名；SHA-256用于完整性校验，不是发布者签名。
- 完整视觉、多显示器和Windows10/多账户等安装矩阵仍有实机验收缺口；本地模型质量与其他既有功能限制参见[v1.3.0说明](https://github.com/Lucency09/Open-ST/releases/tag/v1.3.0)。
