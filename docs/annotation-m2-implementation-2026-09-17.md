# 标注 M2 实施记录

日期：2026-09-17。依据：[已批准的 M2／M3 方案](design/annotation-m2-m3-v0.3.md)。
当前：M2 功能链及增量／缓存优化回归通过；M3 继续单独记录，实际跨屏外观仍待人工验收。

## 范围

- 工具栏新增画笔、直线、椭圆和局部橡皮擦，命令追加保留旧 ID，图标与持续选中态沿用原工具栏。
- 画笔支持单点、圆端点与连接；路径按共享不可变载荷保存，8192 点上限，失败回滚整笔。
- 橡皮直径 8／16／32／64 px，默认 16；参数窗口复用公共 WindowRenderer 下拉表单。
- 擦除以手势开始文档为基线，覆盖裁到当时选区，影响所有已有相交对象；局部擦痕随对象移动，新对象不继承。
- Graphics 的可见几何同时服务绘制、命中和擦除目标查询；擦孔不会因命中容差重新选中。
- 选区、属性和笔迹继续用同一历史；空擦无历史，一笔一次撤销，取消保留 redo。
- Annotation 负责路径／共享擦痕及纯文档操作，状态层管理手势；App 不操作文档数组。
  动态载荷与历史按共享身份去重计费，活动草稿单独限制预算。

## 首轮验证与性能发现

Debug／Release 构建通过；Application 186 通过；图形／模型／工具栏相关 113 项为 111 通过、2 默认跳过。
首轮合计 299 项，297 通过、2 跳过、0 失败。日志：`annotation-m2-application.log`、`annotation-m2-related.log`，位于 testing/testoutput。

独立压力用例使用 544×96 输出、8 条旧擦痕及平滑单调路径，不代表密集自交最坏情况；原始结果如下：

| 点数 | 擦除目标查询 | 实际 SDR 输出 |
| --- | --- | --- |
| 32 | 0.828 ms | 18.878 ms |
| 4096 | 118.614 ms | 62.731 ms |
| 8192 | 381.576 ms | 186.691 ms |

该结果不能解释为显示帧率。它暴露了重建整条新擦痕及所有旧几何的风险，因此在进入 M3 前追加保精度优化：
状态层只查询新增线段并累计目标，仍从固定基线应用整条擦痕；Graphics 使用有界、身份校验的局部几何缓存。
不平滑、不重采样、不降低擦除精度。

## 增量与有界缓存复测

状态层改为首点圆、相邻线段查询并累计目标，最终仍从固定文档应用整条擦痕；同点复用，失败／提交／取消清理累计状态。
Graphics 使用局部几何 LRU，64 项／65536 采样点／估算 16 MiB 上限，检查共享载荷弱所有者身份并清理过期项；
缓存基础路径及最长相同旧擦痕前缀，目标原点变化只做变换。缓存按实际 D2D 工厂隔离，不强持整份历史文档。

| 点数／8 条旧擦痕 | 冷整路径查询 | 热整路径查询 | 实际新增线段查询 | 第二次输出 | 新增 3 点擦痕预览输出 |
| --- | --- | --- | --- | --- | --- |
| 32 | 0.889 ms | 0.201 ms | 0.042 ms | 1.833 ms | 1.857 ms |
| 4096 | 118.344 ms | 60.569 ms | 1.070 ms | 2.805 ms | 3.483 ms |
| 8192 | 375.546 ms | 197.601 ms | 2.103 ms | 2.571 ms | 5.415 ms |

这些是本机一次有限压力测量，不是显示 FPS 或稳定延迟保证。复杂几何首次构建仍慢，当前新增笔迹／擦除轨迹不断变长时也不能保证同样热缓存收益；
密集自交、多对象和实际跨屏连续操作仍需后续观测。不能据缓存优化宣称所有复杂画布掉帧问题已解决。

复测 Application 189 通过；相关图形／模型／工具栏 115 项为 113 通过、2 默认跳过，合计 304 项、302 通过、0 失败。
