## 1. 已确认的产品约束

- 本期是文本翻译：最终截图 → 本地OCR → 统一翻译提供方。在线项只发送文字、不上传截图；本地CTranslate2项不发送任何网络请求。图片翻译另行设计。
- 百度官方通用文本翻译为此前确认的默认第一项；保留Google网页、OpenAI兼容、DeepL、Microsoft和自定义HTTP，并新增CTranslate2本地项，首版仅明确的中文（zh-CN）→英文（en）和英文→中文。所有项复用同一排序、启停、尝试记录与结果协议。
- 用户已明确：连接失败、超时、鉴权/额度/限流、服务异常时尝试下一项；用户取消和输入错误不继续切换。
- 用户已明确：自定义不能只限OpenAI兼容，要能配置请求参数及响应字段映射。
- 代理仅“跟随系统”和“自定义HTTP”。系统无代理/规则指定直连时直连，代理故障不偷偷改走直连。
- Key仍按既定要求明文存data/settings.json；窗口遮罩不等于加密，同目录共享数据的Windows用户读权限语义不变。

## 2. 界面与调用流程

截图工具栏只提供“提取文字”，只做本地OCR。OCR完成或激活已有结果窗均不发起翻译；用户在结果窗明确点击翻译后才处理当前编辑原文，不重复抓屏或覆盖草稿。
复用同一个非模态文字结果窗口，并排显示可编辑原文和只读译文，保留复制原文、复制译文、翻译/重新翻译、取消、关闭。源语言默认auto，目标默认zh-CN；首期目标中英日，源可指定中英日或auto。

1. 用户点击翻译，固定原文、语言及本轮接口列表配置快照。
2. 按列表顺序跳过未启用项；逐个尝试已启用项，同一条目本轮最多一次。
3. 显示“正在尝试：接口名称（第2项/共4项）”；合法译文返回即结束，后续接口不再调用。
4. 允许切换的失败记录原因并继续下一项；全部失败显示逐项摘要，保留原文和旧译文。
5. 用户取消、关闭窗口/截图、修改原文或源/目标语言，立即使整轮失效并取消，不能在取消之后继续下一项。

结果显示最后成功的接口名称，方便识别来源；不再用一个供应商下拉框覆盖全局顺序。使用一个接口时只启用一项即可，不额外设置两套执行模式。
界面区分“本地”和“在线”标识：本地项不上传；失败后若后续启用了在线项，仍可能上传原文。仅启用本地项才是完全离线，不额外增加一套与列表互相矛盾的运行模式。界面明确“失败时可能把原文发送给多个已启用在线接口”。超时后原服务可能已经处理或计费，切换可能产生另一笔调用；取消只取消本地等待和结果发布，不保证撤销服务端处理。
切换目标或编辑原文后，旧译文保留并标为过期；复制仍复制当前显示的译文。旧响应不得覆盖新原文或更新过的请求。
OCR未完成时翻译按钮不可用，也不记录或排队“完成后翻译”意图。截图调整不改变已生成的原文，关闭结果后重新识别新选区。
原IME、Ctrl+A/C/V/Z、模态输入暂停和截图结束清理继续复用；不能把整轮等待变成禁用托盘或无法关闭的模态窗口。

## 3. 有序接口列表与设置

设置页使用通用原生表格，显示名称、类型和只读启用状态，右侧为新增、编辑、删除、上移、下移，双击编辑。启用状态只在条目子表单勾选。自定义HTTP采用单页分组滚动的普通字段和键值表，仅JSON请求体保留多行模板；不编辑整块配置JSON。子表单拥有临时草稿，取消不改父事务，确认按稳定ID一次替换；编辑期间不能因父列表重排命中另一行。

每项有独立且稳定的ID、名称、启用状态、类型、该项参数与凭据。同一种供应商可以添加多项，例如不同OpenAI兼容地址/模型或不同账号；名称和位置不是请求身份。新增生成新ID，删除后不复用旧ID。
默认生成六条内置配置：百度排第一且启用，其他在线项与新增CTranslate2本地项默认停用；用户可将本地项启用并移到首位。此处保留此前默认安排，不把“加入列表”解释成已要求更换默认首选。在线凭据均为空，本地项不需要URL/API Key，只显示内置模型包及可用状态。用户填写自己的百度AppID/密钥；需要故障切换时启用并配置后续项，不会在未选择时偷偷把正文发给Google。
列表建议最多16项，空列表或全部停用时直接提示配置，没有网络请求。凭据缺失的启用项在运行时记录“未配置”并跳过；只有百度时明确引导填写，不内置公共Key。

持久化采用一个结构化JSON字段 `translation.interfaces` 保存有序数组，另保留source_language、target_language及network.proxy_mode/proxy_address。数组顺序即尝试顺序。静态配置预算：每项序列化后最多64KiB、整列最多1MiB；头/query各最多32项、secret最多16项，值最多4096字符，JSON最大32层；Pointer最长256字节、数组映射最多1024项、连接符最多16个Unicode码点。保存前和运行前都验证，不能借外部改JSON绕过。每项形如：

```json
{
  "id": "稳定ID",
  "name": "我的接口",
  "enabled": true,
  "kind": "custom_http",
  "configuration": {},
  "secrets": {}
}
```

具体字段由Translation发布schema、默认值、选项与校验；Settings仅通过App窄回调消费，不链接兄弟Translation。
SettingsEditSession最小扩展结构化JSON草稿、读取和条件提交，和现有字符串/布尔字段一起原子保存。不把数组序列化成JSON字符串，不另写文件管理器。
新增/删除/排序/改Key都先改同一份草稿，“应用”才持久化；取消恢复原配置。外部修改引发原有冲突，文件锁占用立即报错、不等待。结构、模板语法或非法URL不能保存；合法但凭据未填允许保存，实际提交再判定可用性。
恢复本页默认只改草稿；恢复全部默认继续使用既有确认，明确会删除自定义条目、清空密钥并恢复默认列表，确认中不显示密钥值。
尚未发布的旧单供应商14字段草案不作为正式兼容格式保留，整合时移除旧读取/页面路径，避免长期维护两种配置所有权。

## 4. 内置适配器

| 类型 | 协议与参数 | 本程序单项输入保护上限 |
| --- | --- | --- |
| CTranslate2本地 | 进程内C++引擎及固定中英双向模型，无HTTP、无Key；kind=ctranslate2_local | 先遵守全局10000码点，再按所选模型真实token上限判断；不套用HTTP字节预算，不静默截断 |
| 百度（默认） | 官方HTTPS通用文本翻译，AppID/密钥签名，UTF-8原文后表单编码，HTTP200仍检查业务错误 | 1000 Unicode码点，按基础套餐保守限制 |
| Google网页 | 固定候选端点，POST表单q及sl/tl；非官方契约，不绕过验证码或限制 | 2000码点 |
| OpenAI兼容 | Base URL后拼接/chat/completions；非流式model/messages，用户配置Key和模型 | 10000码点，仍可能受模型上下文限制 |
| DeepL | 官方Free/Pro端点、/v2/translate、DeepL-Auth-Key | 10000码点 |
| Microsoft | 官方全球Translator v3端点、订阅Key及需要时的区域 | 10000码点 |

内置类型继续拥有认证、语言映射和响应语义，不把官方请求头/域名搬入Common。固定官方类型不允许无提示改成另一个主机；需要完全不同的请求用自定义类型。
百度签名使用系统CNG，不手写MD5；其文本认证不套用后续图片token/重试规则。原文/签名/密钥不日志。Google只作为用户启用的候选项，失败后是否下一项由本轮链统一判断，适配器内部不私自重发。

### 4.1 统一提供方接口

Translation定义同一 `ITranslationProvider` 领域契约：能力查询、参数/输入校验、一次Execute(text、source、target、profile、deadline、cancel)以及分类结果。能力/静态配置校验不得加载模型或联网，分词、散列和推理等实际工作在既有工作线程内执行。请求不含HWND、截图或强制的HTTP字段；结果统一为Success/NotApplicable/Unavailable/Failed/Cancelled/TimedOut及文本/诊断类别。
能力描述包含语言对、是否支持auto、是否使用网络、输入预算和配置字段。工厂按kind创建适配器，列表调度只消费能力及统一结果，不写“如果CTranslate2则另走流程”的分支。
在线内置/自定义适配器使用Common/Http；LocalCTranslateProvider也放在Translation适配层，调用独立子模块Translation/Local的引擎API。Local子模块只定义自己的文本/语言/模型/取消契约，不反向包含父层ITranslationProvider。HTTP错误与模型错误由各适配器转换为统一类别，下一项选择仍由唯一调度器决定。
统一契约还提供可选的下一次空闲维护时刻及维护/释放资源操作；在线实现无维护需求，本地实现用于缓存卸载。由Translation已有工作线程的有界等待驱动这些通用生命周期入口，不在Local新增定时线程，也不让调度器判断具体引擎类型。
同一条目最多一次、成功停止、用户取消整轮停止、来源修订核验均沿用，不给本地另建窗口、设置文件、线程调度器或失败回退链。

### 4.2 本地中英能力、模型及资源

首版只支持zh-CN↔en，不做日文翻译或经英语中转；在线项仍可按原规则处理日文。明确不支持的语言在模型加载前返回NotApplicable，可按顺序跳过。
2026-10-03 用户批准本地 auto：由 Local 在唯一工作线程中调用 Windows ELS 离线语言检测，检测全文 NFC 副本，实际翻译仍使用原始文本。只接受首选语言对应现有模型的方向，en 及中性 zh／zh-Hans 等归一化为既有英文／中文代码；不从后续候选挑选中英，不按目标语言反推，也不将明确繁体标签强制映射简体。未识别、系统服务不可用、方向不支持时返回不适用并继续已有接口队列；只有本地项启用时保留原文并提示。ELS 不提供公开置信度，短词和混合文本不能承诺准确识别。检测前后检查原截止时间和取消，不增加在线探测或第三方模型。

候选模型：Helsinki-NLP/opus-mt-en-zh与opus-mt-zh-en，分别覆盖英→中与中→英；候选不等于已经下载/选型验收。必须配套固定模型版本、词表、SentencePiece文件、规范化和语言/BOS/EOS标记，英→中候选需要指定简体中文目标标记，不能把CTranslate2的输出默认视为简体中文。
模型卡当前分别标明Apache-2.0和CC-BY-4.0；构建前核对对应固定版本的许可，随包保留署名、许可及转换说明，不能因引擎许可相同就替代模型许可。
拟采用CPU INT8、一个活动任务、2个计算线程，先以beam_size=1验证质量与逐token取消；不引入GPU/CUDA首版运行要求，也不在用户机器安装Python。具体推理后端、候选模型的质量、冷/热耗时和峰值内存须实测，不把此前300～800MB工程预算写成已达到的结果。

模型生命周期归Local：第一次实际使用才校验并加载，仅缓存当前方向的一个模型/分词器组合；切换方向先释放旧组合。多条本地配置按固定模型身份共用有界缓存，不因新增同类条目常驻多份权重。建议后台空闲5分钟卸载，等待用条件变量/既有任务机制，不轮询桌面；正在解码时不卸载。引擎分配器可能保留内存，必须同时测Private Bytes和工作集，以及与OCR缓存叠加的占用，不能保证卸载后立刻回到启动内存。

分词后先核验真实模型token上限（包含全部特殊标记），再执行推理；显式关闭库自带的输入截断。超长返回本地项能力不足，可尝试后续项；保留排布修订仅按原文已有硬换行逐行调用，整文512 token前置门禁不变，单行不拆。换行、空白行及Unicode缩进原样组装，各行共用同一deadline/取消令牌；任一失败不发布部分译文。输出达到预算但没有正常结束标记时返回Truncated，不能当完整成功。实际输入/输出上限来自已固定的模型配置及受控验证，不直接沿用库默认值。

模型与分词文件复用已有模型固定清单/缓存/校验/Release staging机制，扩展本地翻译资源集合而不是再造下载器和打包器。清单记录来源提交/URL、SHA-256、许可、转换器版本、INT8配方及转换产物校验值；权重不入Git。运行期缺失/损坏只报本地项不可用，不下载、不悄悄换模型。校验至加载保持同一模型版本及文件身份，不能只散列路径后无保护重开。
依赖继续走vcpkg manifest；先核对固定baseline，缺可用端口时使用受版本控制、固定来源的overlay port，不整体升级依赖树或手工复制第三方DLL。转换工具可作为开发阶段工具，但交付程序仅消费经验证的C++运行库、权重和分词文件。

### 4.3 本地取消与顺序衔接

本地项使用统一单项deadline，计算预算包括文件校验、模型加载、分词和解码；10秒连接超时只适用于在线项。CTranslate2的逐token取消回调要求beam_size=1，输入编码/模型加载并不保证可立即中断。
超时先撤销结果发布资格并请求合作取消；必须等本地Execute实际收尾、停止访问该输入/模型后，才允许尝试下一项，不能留下本地future继续计算同时启动在线请求。若收尾期间整轮120秒预算已耗尽，则结束整轮，不再发送在线请求。因此本地不可中断阶段可能令收尾超过预算，不能宣传硬性120秒强制结束；需要硬时限隔离进程时另行审核。
用户主动取消始终终止整轮，不因本地返回Cancelled而自动联网。模型缺失/损坏、该方向不支持、token预算不足等作为本地条目不可用/不适用处理；进程级内存分配失败仍停止整轮。

## 5. 自定义HTTP的明确能力边界

自定义支持静态的单次HTTP文本接口，不限OpenAI格式；首版提供GET、POST、PUT、PATCH，URL、请求头、查询参数、正文及响应映射均可配置。
不执行JavaScript/脚本或任意表达式；不支持SSE流式、图片/multipart上传、OAuth多步登录或用户编写的动态签名算法。需要这些协议时由专用适配器扩展，不能把“任意HTTP配置”宣传成能无代码接入一切认证系统。

### 请求模板

- URL的协议/主机/路径由用户固定填写；查询参数单独编辑，不用翻译原文改变目标主机。
- 支持变量 `{{text}}`、`{{source}}`、`{{target}}` 及 `{{secret.名称}}`。每项显式声明支持的源/目标语言及语言码映射，例如zh-CN→zh、ja→jp；映射同时界定能力，缺少所选语言/auto支持则跳过该项。固定语言接口只声明一个支持值；声明多种源/目标时，请求模板必须实际引用对应变量，不能切换目标后仍发送硬编码目标。仅自动检测的接口可只声明auto并省略源参数。未声明变量不能发送。
- 请求头/查询参数为键值表，正文可选无、JSON、表单、纯文本。GET不发送正文。
- JSON模板存为实际JSON对象/数组，变量只在字符串值中替换，再由nlohmann/json序列化，不能直接拼接整段JSON让引号/换行破坏结构。
- 表单/查询参数先替换原始值再进行UTF-8百分号编码，避免二次编码；纯文本正文保持文字。请求头替换后拒绝CR/LF/NUL。
- Secret单独命名并遮罩输入；模板引用名称，不复制真实Key到展示用示例。全部配置仍按既定要求明文保存，不承诺加密。
- 默认HTTPS；明确配置HTTP时设置页和结果窗口持续提示传输风险。保持证书校验，禁止自动跨源重定向或重放凭据。

### 响应映射

- JSON或纯文本两种模式。JSON字段定位复用nlohmann/json的JSON Pointer，例如 `/data/translatedText`、`/choices/0/message/content`，不引入另一个脚本引擎。
- 单文本模式取指定字段，必须为字符串；数组模式配置数组路径、每项文本路径和连接符，保留顺序组合完整译文；任一项类型错误不发布部分结果。
- 可配置一个成功条件（字段路径与预期JSON标量值，例如/code等于0）；未配置时要求HTTP2xx及合法非空译文。成功条件失败或非成功HTTP时，可读取业务错误码并映射鉴权、配额、限流、输入或服务异常。
- HTTP200不直接等同翻译成功；字段缺失、空结果、结构不支持均为协议/服务错误，按切换表处理。非2xx不能靠正文“成功”字段伪装成功。
- 不把服务端整段报错直接显示或写日志；只显示预先定义的错误类别，避免回显原文/密钥。纯文本模式也须通过HTTP状态、编码和长度检查；Common/Http有界提供Content-Type（最多256字符），Translation拒绝text/html、application/xhtml+xml及典型HTML文档开头，保守地将其归协议失败，不作HTML渲染。

## 6. 失败分类与有界切换

| 情况 | 本轮处理 |
| --- | --- |
| 用户取消、窗口/截图关闭、原文/目标/链配置发生变更 | 立即终止整轮；不得再尝试下一项 |
| 全局输入为空、非法编码、超过全局10000码点、源/目标值无效或相同 | 本地停止，不请求任何接口 |
| 条目停用、缺凭据、本地模型缺失/损坏、该条目不支持语种/长度 | 请求前跳过并记录原因，可尝试下一项；不截断或分段 |
| 连接、代理、TLS失败；单项超时 | 关闭当前请求后按序尝试下一项；代理模式保持不变 |
| 鉴权/权限、额度/余额、限流、上游5xx、禁止跟随的重定向、协议/空结果/截断/模型上下文不足 | 记录此条目失败，按序尝试下一项 |
| 未识别业务语义的HTTP400/422，或适配器/自定义映射明确报告“输入错误” | 停止整轮并提示修改原文/参数；不把原文错误自动扩散到其他服务 |
| 本地全局配置结构无效、资源分配失败、整轮预算耗尽 | 停止整轮；保留诊断分类，不继续发送 |
| 合法成功译文 | 立即结束，后续项不调用 |

分类优先级固定：用户取消/本地全局输入校验 → 内置已识别业务错误或自定义显式映射 → HTTP状态兜底。已识别的鉴权/配额/上下文不足即便使用HTTP400也按其业务类别切换，未知400/422才停止，不能对同一响应给出相反操作。

“某接口的已知长度上限较小”与“原文自身不合法”分开：前者可在发送前跳过，后者不能通过换服务解决。自定义业务错误映射没有匹配项时归服务/协议失败，不将原始报错当成功文本。
每个稳定ID每轮最多一次；不会回到列表开头、循环尝试或重发同一条目。允许用户主动点击重新翻译开始新一轮。

建议在线连接超时仍为10秒，每项执行预算30秒，整轮执行预算120秒；本地不可中断阶段的收尾例外见4.3，不承诺强制墙钟终止。每项截止时间取“本项开始+30秒”和“整轮开始+120秒”的较早者；整轮耗尽后显示未尝试项，不暗示所有接口都失败。这是相对旧整轮30秒的明确修订，避免第一项超时就没有切换机会。
所有提供方统一受全局10000码点和最终UTF-8译文1MiB保护，本地还额外受模型token限制。以下传输预算仅适用于在线项：每项展开并编码后的请求体64KiB、请求头8KiB、完整URL（含GET查询）8KiB UTF-8、成功响应1MiB、错误正文16KiB；自定义最多10000码点。必须在模板替换/JSON序列化/百分号编码后计算；某条目展开超预算归该项能力不足并跳过，不把合法原文误报为全局错误。JSON解析先做深度/节点预算检查；数组拼接后的最终UTF-8译文也限制1MiB，连接符计入，不静默截断。上限不因排序或切换绕过；只保留有界尝试摘要，不累计保存每家原始响应。

## 7. 状态和生命周期

TranslationClient唯一拥有整轮快照、顺序/索引、当前尝试、取消令牌、成功结果和有界失败记录，Common/Http只执行单次请求，不知道下一项。
整轮快照包括原文、语言、列表版本和每条启用配置；不边执行边读取可变Settings。统一调度等待当前提供方Execute完成后才进入下一项。在线适配器的Perform返回前已执行WinHttpCloseHandle、停止发送并隔离回调状态，以此为在线请求的本地逻辑结束边界；本地适配器则要求推理实际收尾。HANDLE_CLOSING最终通知可稍后到达，底层缓冲由旧回调状态保活，不访问新项或UI草稿；不在UI线程等待该通知。此边界不承诺上游服务器已停止处理。
整个截图文字翻译路径最多一轮活动任务，不并行竞速。关窗后立即重开或创建新截图，旧请求未真正结束仍拒绝新提交，避免换窗口绕过单任务。

每个结果带单调runId、截图会话ID、原文修订、源/目标、配置修订和成功条目ID。窗口全部核验匹配才显示。修改原文、语言或应用接口列表设置时，撤销整轮资格并取消，不自动重发；外部进程配置变化按下一次读取生效。
TextResultWindow拥有唯一原文草稿和当前显示译文；旧译文过期判断包含原文/源目标/列表配置修订，不只比较文字。OCR完成只首次填充原文，不覆盖已编辑内容或原生撤销历史。
通知仅传稳定编号，结果可从任务快照补收；不借用窗口指针。空闲停补收定时器，退出清理先取消OCR与翻译并异步等收尾，再关闭日志；关窗不join，不强杀工作线程。

## 8. 复用与模块依赖

| 模块 | 职责与变动 |
| --- | --- |
| Application/Translation | 统一ITranslationProvider、在线/本地适配器、custom_http模板/映射、配置schema与整轮调度；不接收图像、不读Settings路径、不创建窗口 |

依赖保持Application→Translation/OCR/Settings/Graphics/Export，Translation→其Local子模块和Common/Http，Update→Common/Http，Local→CTranslate2/分词依赖及Common通用能力，无兄弟或子模块反向依赖。旧单供应商调度/字段/私有类迁移后删除，不保留空包装或两套网络实现。
Update只迁移通用底层，保留原GitHub头/可信HTTPS跳转/资产校验/受保护下载及安装器交接后关闭关于窗口，不使用翻译的自定义代理或切换链。

## 9. 代理、密钥和日志

代理仅system（默认）/custom。系统解析明确无代理或DIRECT规则时直连；配置读取/解析错误、已选代理不可达和407不是“无代理”，不自动绕开。切换在线接口时继续使用本轮固定代理选择；CTranslate2本地项不创建HTTP请求，不使用任何代理。
自定义HTTP代理接受host:port或http://host:port，不支持内嵌账号/路径，首版不加代理认证字段；127.0.0.1:7897可由用户填写，不硬编码开发机代理。

Key、Secret、模板配置仍明文保存在程序旁data/settings.json，界面说明共享目录与便携迁移语义，不转AppData或DPAPI。恢复默认、失败摘要、日志不能回显Key、签名、Authorization、完整URL参数、请求/响应正文。
当前服务阶段只展示接口名称和序号，不展示正在发送的认证头。所有返回文本只作文本显示，不解释为指令、HTML或可执行内容。

## 10. 分步施工与验收

1. 保持已获准的公共Http、Update迁移、readOnly/password及内置provider纯协议；其测试独立完成。
2. 新修订批准后，先完成有序配置schema和Settings原子草稿，再实现内置适配器+自定义模板/JSON Pointer映射的纯逻辑测试。
3. 实现整轮顺序执行：成功停止、跳过配置不全项、各类失败、取消屏障、每ID只一次、单项/整轮超时、关闭后重开不能并发。传输用fake与本机服务器，不调用真实付费API。
4. 演进结果窗口及截图入口；启用列表设置后无需重启，改变设置使旧结果过期，不自动发送。保留OCR纯本地入口和所有复制/撤销/模态边界。
5. Debug/Release、功能开关组合、旧OCR/Update/About回归与打包；构建变量EnableTranslation=true硬编码在脚本顶部，遵循用户已确认的构建习惯。
6. 先独立验证中英双向模型质量、分词一致性、特殊标记、断网可用、冷/热耗时、与OCR叠加内存、关闭/超时收尾和超长无截断；纯本地链必须零HTTP调用，混合链只允许访问启用的在线后续项。本地模型预算和许可未落实前不进入发布包。
7. 用户配置真实凭据后主动验收完整链。测试不得擅自读取其密钥或上传截图；合成样例连通、fake协议通过不写成线上验收。

额外用例：接口同类型多实例/重排/删除与稳定ID；JSON结构化字段冲突；占用锁立即失败；模板Unicode、引号、换行、&+%；缺变量/非法字段路径；数组译文不部分发布；HTTP200业务错误；无接口/全停用/全失败；第一成功后后续零调用；用户取消和输入错误时后续零调用；超时切换有记录但不宣称原服务撤销。
