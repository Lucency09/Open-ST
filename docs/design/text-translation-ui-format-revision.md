- 表格旁提供新增、编辑、删除、上移、下移；双击行打开编辑窗口。
- 主表只显示启用状态，在编辑窗口勾选；不保留原下拉列表及复制、独立启停按钮。
- 新增／编辑窗口顶部为名称、接口类型、启用；下方只显示当前类型参数；本地项显示模型状态；2026-10-03后续批准增加快速／均衡／质量档位及说明。
  类型在新增时选择，编辑已有条目时固定，底部确定／取消。
- 自定义 HTTP 也改为普通字段和键值列表：全部位于同一页，按分组上下滚动。
  JSON 请求体允许保留单独的多行模板框；不再要求编辑完整配置 JSON。
- 本地译文中的实际换行、空行、行首缩进必须与原文对应。
- 截图工具栏不显示翻译按钮；用户只能先提取文字，再在文字结果窗口明确点击翻译。

## 界面方案

主表位于翻译设置页，操作按钮在右侧竖排；默认源语言／目标语言保留在表格下方。
原有独立翻译网络页保留；本轮不移动代理设置。主设置窗口的应用、确定、取消及恢复默认沿用原事务。
列表行顺序就是接口尝试顺序，不增加点击表头自动排序，以免显示顺序与执行顺序不一致。

新增／编辑共用一个普通模态表单。新增选择类型后显示该类型字段；已有条目不允许改类型。
本地项显示模型包、文件状态及首次使用才完整校验的说明；在线内置项显示对应账号、密钥、地址等字段。
只有子表单确认成功才一次替换父草稿；主窗口应用之前不写盘、不发起请求。
切换正文／响应模式时保留本次未提交草稿，切回时不能丢失输入；保存只生成当前模式有效的配置。

自定义 HTTP 采用以下纵向分组，不加标签页或左侧导航：

| 分组 | 内容 |
| --- | --- |
| 基本信息 | 名称、固定类型、启用、请求方法、URL、源语言／目标语言映射 |
| 请求 | 请求头表、查询参数表、正文模式；无正文、JSON模板、表单键值表、纯文本模板 |
| 响应 | 纯文本／JSON；单字段或数组提取、字段路径、连接符；可选成功条件及业务错误映射 |
| 密钥 | 名称列表及遮罩值编辑 |

键值表复用统一列表和新增／编辑／删除子表单，不开发另一套内联单元格编辑机制。
JSON Pointer 的空路径、真实换行连接符、成功比较值的字符串／数值／布尔／null类型、
七类业务错误映射、语言映射定义能力、空凭据可保存等现有能力均须保留。
JSON 正文模板仍能表达嵌套对象和数组；密钥通过命名引用，列表和诊断不得明文显示密钥值。

## 本地文本排布

现状：Local 将完整原文一次送入 SentencePiece／模型，空白归一化后没有恢复原文结构；
结果窗只是显示引擎返回内容，不能在 UI 里猜测句子并重新插入换行。

拟在 Local 内按原文已有硬换行拆出内容行，CRLF视为一个分隔符，保留分隔符、连续／末尾空行、
纯空白行和行首空白（含空格、Tab）的原始内容。空白行不调用模型；非空内容行顺序翻译后重新组装。
文本框自动折行不视为输入换行；本轮不恢复截图坐标、字体或表格列宽。

范围限定：先保留原有整文分词及512 token上限校验（包括原特殊标记规则），然后各内容行仍须满足
单次推理限制；不拆长行，不借本轮增加超长文本分段能力。整体10000码点及最终1MiB预算不变，
输出中的分隔符、缩进也计入总预算。

一次本地提供方 Execute 仍是一项任务：模型加载、全部分词和全部行推理共用原单项30秒deadline及取消令牌，
不按行重置计时；整轮120秒预算和旧任务收尾前不接新任务的规则不变。
任一行失败、截断、超时或取消，整项不发布部分译文。用户取消、内存不足、全局输入错误或整轮预算耗尽
仍停止整轮；只有原失败表允许后备的错误，才由原调度器将完整原文交给下一提供方。
不逐行切供应商、不混合不同供应商结果。本轮只改本地输出结构，不擅自拆分在线请求。
逐行推理会减少跨行上下文，不能承诺译文质量完全不变；旧模型质量缺口仍保持未验收。

## 模块职责与复用

| 模块 | 拥有的状态、输入输出与变动边界 |
| --- | --- |
| Common/WindowRenderer | 最小扩展通用原生表格：列／行、稳定选中值、双击／Enter激活、刷新、禁用、键盘与DPI；以及通用控件／分组可见性和重新布局。复用既有滚动、字体、模态、错误处理。不得认识翻译配置、密钥或接口顺序。 |
| Settings | 借用唯一SettingsEditSession，拥有UI选择和子表单临时草稿；按稳定ID新增、替换、删除、排序。字段选项／配置规则从App注入领域元数据，不链接兄弟Translation，不另写配置文件。 |
| Translation | 保持提供方、完整请求及唯一顺序调度；按需发布自定义表单所需枚举／字段描述，协议和校验继续归领域模块。 |
| Translation/Local | 拥有拆行结构、分词、推理、同一deadline与组装；不访问窗口、设置或在线提供方。 |
| Application／CaptureTextSession | 只编排OCR及结果窗显式翻译；移除自动翻译意图、相关布尔参数和工具栏翻译分支，不复制原文。 |
| CaptureToolbar | 移除翻译命令、图标及命令范围校验中的旧上界；保留提取文字命令和其他截图工具。 |
| TextResultWindow | 继续唯一拥有原文及显示译文，保留翻译按钮和现有取消／过期／复制行为；不重新猜测排版。 |

已有Renderer只有select等控件，没有表格；新列表必须放在公共模块，不能在Settings自建控件工厂或消息循环。
现有content/column/row与滚动足以实现单页分组，不增加分页机制；可见性扩展只负责通用布局，不承担业务校验。
现有的翻译执行协议及保存JSON结构保持兼容。废弃的下拉列表、工具栏翻译入口和自动意图路径同步清理。
