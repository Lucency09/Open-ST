# 0.3.0 快捷键管理与设置页设计

状态：用户于 2026-09-12 明确批准，代码与专项自动验证完成；产品人工验收待确认。

对应实现进度中的“独立快捷键管理模块”。本文记录已批准范围，不代表全部实现或验收已经完成。

## 1. 本轮范围

新增独立快捷键模块，集中管理全局截图注册与截图会话按键匹配；设置页允许修改全局截图组合，
默认仍为 Ctrl+Alt+Q。局部复制、保存、分层取消保持现有语义，本轮不开放局部按键配置。

贴图窗口的 Esc 继续由 PinWindow 根据本窗口焦点、目标和可交互状态处理。
鼠标滚轮、右键菜单及其他产品功能不迁入快捷键模块。不引入键盘全局钩子、轮询或第三方依赖。

## 2. 已核对的现状

- App 在启动时硬编码注册 Ctrl+Alt+Q，退出和清理路径分别注销；WM_HOTKEY 当前未核对注册 ID。
- 截图窗口识别 Enter/Ctrl+C 复制、Ctrl+S 保存，通过现有工具栏门禁和命令投递进入业务。
  Esc 直接进入分层取消；需保持当前修饰键、重复按键和取消规则，避免迁移时改变行为。
- Settings 已有原始字段基线、草稿、一次条件提交、外部同键冲突检查及保存后副作用重试。
  当前仅打开语言和自启字段，恢复默认与重新加载需随新页面扩展。
- WindowRenderer 目前没有组合键录入控件；ProcessDialogMessage 会先处理 Enter/Esc，
  因而新增控件必须同时调整消息导航顺序，不能仅添加子窗口过程。
- 托盘、欢迎说明及注册失败提示含硬编码默认组合，需要区分默认值、已保存值与实际生效值。

## 3. 模块与接口边界

| 位置 | 职责 |
| --- | --- |
| Application/Hotkeys，目标 OpenST::Hotkeys | 组合解析与规范化、允许范围校验、全局注册所有权、候选注册、活动消息匹配、截图会话按键到命令的映射。只依赖标准库和 Windows SDK。 |
| Application/source/app_hotkeys.cpp | 读取 Settings、适配 Hotkeys、处理注册状态、将匹配结果送入既有业务入口。 |
| Application/source/app_callbacks.cpp | 集中组装 Settings 与 Renderer 所需的验证、显示、注册准备和完成等窄回调。 |
| Settings | 设置键、默认资源、草稿、条件提交、字段错误与页面行为。 |
| Common/WindowRenderer | 通用组合键录入、焦点和键盘导航、数值组合绑定与宿主提供的显示文字；不认识截图命令或设置键。 |

Settings 与 Hotkeys 不互相包含头文件或链接；Renderer 不依赖 Hotkeys。
边界使用简单值、各模块自己的结果和回调，由 App 转换，不为了共享结构增加公共业务目标。
Hotkeys 返回命令与错误类别；是否允许截图、选区代次、模态忙状态及输出逻辑仍由 App 决定。

## 4. 设置数据和允许组合

在 default_settings.json 增加字符串设置 capture.hotkey，默认值为 Ctrl+Alt+Q。
沿用动态设置接口，不新增设置键枚举或注册表。组合保存为固定、与界面语言无关的 token，
顺序为 Ctrl、Alt、Shift、主键，例如 Ctrl+Shift+F8；界面显示由独立格式化过程生成。
解析拒绝重复修饰键、多主键、未知 token 和不支持的组合；录入产生规范值。

本轮建议支持范围：

- A–Z、0–9：至少包含 Ctrl 或 Alt，可再含 Shift。
- F1–F11、F13–F24：允许单键或 Ctrl/Alt/Shift 组合。
- 不开放 Win、F12、纯修饰键、导航/编辑键、OEM 标点、多媒体键、鼠标键和多段序列。
- Ctrl+C、Ctrl+S 与现有截图会话操作冲突，明确拒绝作为全局截图组合。

这些本轮产品取舍已随方案批准。Windows 保留的 Win 组合及 F12 限制见
[RegisterHotKey 官方说明](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey)。
语法合法不代表可注册，最终以实际 RegisterHotKey 结果为准，不承诺拦截其他程序已占用的组合。

## 5. 页面与录入行为

设置新增“快捷键”页，按左侧功能描述、右侧实际快捷键排列多行；只有全局截图行可编辑，其余行只读。
包含当前生效状态；不显示独立注册或清理按钮，由“应用”统一处理保存、生效和失败重试。
复用底部应用、确定、取消、恢复本页默认、重新加载按钮；不增加无业务的选项。

- 修改组合只更新草稿；应用或确定才尝试注册并保存。取消丢弃未保存修改，不撤销此前应用。
- 恢复本页默认经确认后只改当前页草稿；默认资源读取或语义验证失败则保持草稿。
  字段归属通过控件实际页面确定，移动布局后仍遵守本页范围，不硬编码只支持 general 页。
- 重新加载沿用已有丢弃草稿确认及读取失败保护；读取设置本身不偷偷切换系统注册。
- 状态分别显示草稿、已保存配置与当前生效情况；注册失败时明确显示仍生效的旧组合或未注册。
- 未生效或仍需恢复时，即使草稿未变化，“应用”也可用：先核对已保存目标仍一致，再尝试注册；
  没有草稿变化时不借重试写回配置，其他字段有变化时仍按一次批量提交处理。

Renderer 增加通用组合键控件及类型化绑定。控件激活后进入录入状态，完整合法组合立即更新草稿，
同时更新“应用”状态，不必先按 Enter 或移开焦点。Enter 只结束录入，Esc 恢复本次录入开始前的草稿且不关闭设置，
Tab/Shift+Tab 结束录入并导航；结束时不重复通知相同变更。原始非法配置也通过宿主回滚回调真实恢复。
离开控件或切页时结束录入，完整且合法的组合接受为草稿，未完成组合保留上次值；
窗口失去前台或销毁时取消未完成录入。再次点击或键盘激活可重新录入。

录入消息优先于普通对话框 Enter/Esc；覆盖 WM_KEYDOWN/UP、WM_SYSKEYDOWN/UP、
WM_SYSCHAR、F10 和修饰键释放，录入期间不会误提交设置或激活菜单。
忽略按住重复，普通键消息和 WM_HOTKEY 双路不重复修改草稿。

录入期间保留原全局注册但暂停截图触发。仅当录入控件仍有前台焦点且录入状态有效时，
App 才将匹配当前活动注册的 WM_HOTKEY 转交控件；不得把历史排队按键录成新草稿。
开始与结束录入均设置消息时间边界，失焦、切页、关闭和异常路径必须结束暂停状态。
其他程序占用的组合可能无法完整送到控件；明确提示重新选择，不用钩子抢占系统输入。

## 6. 注册与保存顺序

整个关键区在 UI 线程同步执行，不打开模态窗口或主动泵消息。准备前完成可能失败的解析与分配。

1. Settings 完成所有需提交字段的业务校验，进入现有忙状态。
2. App 请求 Hotkeys 准备候选。组合与当前活动组合相同则复用；不同则使用独立 ID 注册，
   旧注册仍有效。候选注册使用 MOD_NOREPEAT，准备阶段的候选消息不能触发业务。
3. 注册失败时不提交任何本批设置，保留原活动组合与全部草稿，显示冲突或系统错误。
4. 准备成功后，Settings 通过原有一次 Commit 条件提交本批变化，保留未知字段及冲突规则。
5. 读取失败、外部同键冲突、写入失败或异常均撤销候选；旧注册从未解除。
   作用域守卫保证任何提前返回均完成候选回收。
6. 保存成功后直接激活已准备的注册。激活只做预先准备好的无异常状态切换，
   不执行新注册、分配、写盘或消息泵，随后注销旧注册并刷新显示。
7. 候选撤销或旧注册注销失败时，将对应注册保持为不可分派、待清理状态，报告故障并提供重试。
   保存成功的新配置不因旧注册清理失败而回滚；不得把清理失败冒充完全成功。

语言和自启仍沿用现有保存后应用与独立失败重试机制；它们失败不能伪称本批没有保存，
也不能撤销已经激活的快捷键。本方案不承诺配置文件与系统注册跨进程或跨崩溃原子性。

候选、活动、待清理注册均有明确所有权，正常退出及“退出并清理”统一经过 Hotkeys 回收。
注册 ID 在进程内单调分配、不复用旧 ID；可用 ID 耗尽时明确失败并保留原注册。
同组合复用不消耗新 ID；待清理的同组合重试应复用已确认仍持有的注册，避免与自身冲突。

## 7. 消息、启动与文字一致性

- WM_HOTKEY 校验活动 ID、修饰键、主键和有效时间边界；拒绝候选、已退役、无关和过期消息。
  DWORD 消息时间比较处理回绕；暂停开始和恢复时建立截断边界，拒绝忙期间排队、恢复后才到达的触发。
- 全局匹配仍进入 StartCapture 的现有准入。截图复制保存仍使用 toolbarGate、输入时间、
  截图/选区代次和 PostToolbarCommand；不直接调用 Export 或绕过模态防重入。
- 启动时旧文件缺少新键则消费有效默认，不因默认回退自动写用户文件。
  非法配置明确提示并尝试有效默认；默认也无效则保持未注册，托盘仍可截图。
  合法配置被占用时保持未注册并提示，不静默换另一组合；设置可修改或重试。
- 运行中保留已生效状态；外部编辑文件不会自动抢换注册，需明确应用或重试。
- 托盘菜单、工具提示、设置状态及注册失败提示使用受控占位符，显示实际目标或实际活动组合。
  未注册时显示未注册状态，不继续宣称某个组合可以截图。
  欢迎页显示有效初始配置并说明确认后尝试启用，避免在注册前宣称已生效。
- 文本继续经 GetUiText 查询，新增资源包含中英日；按键名称使用统一显示规则。

## 12. 用户体验修订（2026-09-12）

用户反馈录入后“应用”始终灰色：原实现只更新预览，直至结束录入才修改草稿，禁用按钮无法接收点击以结束录入。
按用户要求改为完整合法组合立即修改内存草稿，系统注册与持久化仍只在“应用／确定”进行。
用户明确要求左右多行布局，并确认仅全局截图键可编辑，复制、保存、分层取消和关闭贴图只展示固定组合。
用户明确选择删除“重试注册／清理”按钮，由“应用”重试；对应保留无草稿变动时的待生效判断及冲突核验。
Renderer 增加通用 row 容器，组合键可以省略独立标签；窄窗口、DPI、文字换行和输入错误仍由 Renderer 处理。
本修订已经子 Agent 复核，不扩大到局部快捷键配置或其他模块功能。

修订已实现：相关模块 189 项自动测试通过，2 项人工默认跳过；Debug /W4 /WX 和 Release 构建通过。
真实窗口回归覆盖输入框按键后立即启用“应用”，并验证点击应用完成保存；布局回归验证固定描述列、
剩余输入宽度、省略标签、可换行长文本及窄视口边界。人工观感仍待用户确认。
