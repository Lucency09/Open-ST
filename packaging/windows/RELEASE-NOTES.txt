Open-ST v1.3.0 Windows x64

本版更新
- 长文本自动按句末、换行等边界分段，顺序调用本地或在线接口，完成后拼接译文；无需额外设置。
- 每个在线接口可独立选择跟随系统、直连或自定义HTTP代理，新增/编辑接口时即可配置。
- 删除设置窗口的全局“翻译网络”页。升级时将旧全局代理迁入缺少网络配置的在线接口，已有独立配置不覆盖。
- “测试连接”使用当前接口未保存的代理草稿，正式翻译与有序后备也分别使用对应接口的配置；本地接口不显示网络配置。

便携版与安装包均包含本地OCR和中英翻译模型，无需另外下载模型。
便携版：完整解压到可写的本地专用目录，运行Open-ST.exe。手动覆盖升级前退出程序并备份data，覆盖程序和resources时保留data。
安装版：支持当前用户/所有用户安装和自定义本地专用目录。安装更新时自动关闭已核验的目标实例，15秒未退出再强制结束；升级前请自行保存截图、编辑文字和贴图。
卸载默认保留data。设置、日志和更新缓存位于程序旁data；所有用户卸载前，各用户应关闭自身开机启动登记。

运行要求：Windows 10 22H2 / Windows 11 x64；Microsoft Visual C++ x64 Runtime。
官方运行库：https://aka.ms/vs/17/release/vc_redist.x64.exe
本版程序和Setup未签名，Windows可能显示发布者或信誉提示；SHA-256用于完整性校验，不等于发布者签名。

已知限制
- 本地中英模型仍可能出现误译或漏译，调高档位不保证每句更准确；分段以固定200 Unicode标量向下选择边界，极长无边界文本需硬切，自动检测按片段进行。
- 普通翻译全文最多100000 Unicode标量；连接测试仍为单次完整请求，最多10000标量。整轮120秒及输出预算不因分段而增加。
- 直连仅指不使用系统HTTP代理，不改变VPN或底层网络路由；代理失败不会自动改为直连。
- 已完成定向及真实窗口自动化测试；新接口编辑布局的完整视觉/DPI验收尚未完成。
- 输入法、混合DPI、HDR游戏观感及不同显卡驱动仍需更多实机反馈。
- Windows 10、所有用户提权、多账户会话、缺运行库等安装矩阵尚未全部实机验收。
- GPU设备丢失恢复、复杂标注性能等仍有后续改进事项。
